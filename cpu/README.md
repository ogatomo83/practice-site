# 図解 CPU

コンピュータの仕組みを、0 と 1 からゲームが動くところまで、ブラウザの中で動く小さな CPU（RISC-V RV32IM のエミュレータ）と論理回路シミュレータで試しながら学ぶ学習サイト。序章 + 20 章 + 付録。設計は `DESIGN.md`。

## 読む

`site/index.html` をブラウザで開く。サーバは不要で、実行環境は自作なので読み込むものもない（フォントだけ Google Fonts）。

- 本文のプログラム（アセンブリ）と回路は「実行」ボタン（Ctrl / ⌘ + Enter）でその場で実行でき、書き換えもできる。「元に戻す」で最初の内容に戻る。1 ブロック = 1 つの独立したプログラムで、毎回新しい機械で実行する
- アセンブリの出力欄：コンソール、画面（使ったときだけ。32 × 32 ピクセル）、終了の理由、実行した命令数、変化したレジスタ（10 進と 16 進）。ブロックの指定に応じて、メモリ（16 進のバイト列）、パイプラインの計測（サイクル数、CPI、命令 × サイクルの表）、キャッシュの計測（ヒット率、アクセスの履歴）。エラーは日本語の理由と、エディタ上の該当行の色で示す
- 「動き続ける」印のブロックはアニメーション。「停止」/「再開」ができ、画面をクリックするとキーボードの入力がプログラムに届く（矢印のボタンもある）
- 回路の出力欄：真理値表（バスは 10 進。「2 進で表示」「途中の線も表示」で切り替え）。記憶のある回路は波形とタイミング表
- 上部の「CPU を見る」で、画面の下にパネルを出す。直前に実行したプログラムを「1 命令進む」「戻る」「最後まで」「最初から」で動かし、次に実行する行（ソース上で光る）、機械語 32 ビットのフィールドの色分け、直前の命令がしたこと（ALU の 2 つの入力・演算・結果と、制御信号 RegWrite / ALUSrc / MemRead / MemWrite / MemToReg / Branch の値も出る。第 16 章の図・表と同じ名前）、レジスタ 32 本（書いたものに色）、メモリ（.data とスタック付近。読み書きしたバイトに色。欄が狭いときは 1 行 8 バイト）、画面、コンソールを見る。出力欄の「ステップ実行で見る」からも開ける。「ステップ実行」印のブロックは、出力欄にこの画面がそのまま出る
- 各章の最後に「確認問題」。自分でプログラムや回路を書いて「答え合わせ」を押すと、模範解答と同じ結果か（コンソールの出力、レジスタ、メモリ、画面、真理値表のうち問題が指定したもの）を判定する。毎回新しい機械で実行するので、何度でも試せる。正解した問題はブラウザに記録され「正解済み」になる
- `site/playground.html` は実験場。アセンブリ（エディタ + いつも開いている「CPU を見る」+ 連続実行、速さ = 1 フレームあたりの命令数、サンプル 6 本）と論理回路（サンプル 5 本）

## 原稿の記法（確定版は `DESIGN.md` の末尾。意味の正は `grade.js`）

図解 Rust / PostgreSQL と共通のもの（front matter、`## 見出し {#id}`、`:::note` `tip` `warn` `key` `hist` `deep` `try` `cols`、` ```fig 種類 キャプション `）に加えて：

- ` ```asm run [属性] ` … 実行できるアセンブリ。開始番地は `_start`、なければ `main`、なければ 0
  - `title="..."` 見出し / `error` エラーになる例 / `anim` アニメーション / `limit` 上限で打ち切られるのが正しい例 / `break` ebreak で止まる例 / `step` 出力欄にステップ実行を出す
  - `regs="a0,t0"` 出力に出すレジスタ（書かなければ変化したもの全部）/ `mem="0x8000,16"` 出力に出すメモリ
  - `maxsteps="N"` / `seed="N"` / `pipeline`（`pipeline="noforward"`）/ `predict="none|taken|1bit|2bit"` / `cache="容量,ブロック,連想度[,ミスペナルティ]"`（4 つ目は省略可、既定 10 サイクル）
- ` ```logic run [title="..."] [error] ` … 実行できる回路
- ` ```asm ` / ` ```asm norun ` / ` ```logic ` / ` ```c ` / ` ```console ` / ` ```text ` … 実行しない例（ハイライトだけ）
- ` ```fig circuit|wave|pipe … ` … 論理回路図、タイミング図、パイプライン図（spec は `diagrams.mjs` のコメント）
- `:::err メッセージ` … エラー解説のカード
- `:::quiz 見出し` … 確認問題。中に問題文と次のブロックを書く。ID は `chNN-n`
  - ` ```asm answer [regs="a0"] [mem="0x8000,16"] [screen] [console] [exit] ` … 模範解答（必須）。既定はコンソールの出力を比べる。属性を書くとそれを比べる
  - ` ```logic answer [only="nand"] [maxgates="5"] ` … 回路の問題。出力の表を比べる
  - ` ```asm given ` … 読者のコードの後ろに連結されるコード（関数だけ書かせる問題の main など）。問題文の下に表示される
  - ` ```asm starter ` / ` ```logic starter ` … 入力欄の初期値
  - `:::hint` … ヒント（折りたたみ）
- 知らない属性を書くと、ビルド時に「注意」が出る

## 検査

スクリプトと `node_modules` はスクラッチパッドに置く（サイトの中には入れない）。

- `check-chapter.mjs chNN …` … Node だけで章を検査（実行ブロックの error の印、図、確認問題の模範解答・再現性・別解・誤答）
- `check-samples.mjs` … 実験場のサンプルを Node で実行
- `browser-check.mjs [chNN …] [--shots]` … ヘッドレス Chrome で file:// から開き、全実行ブロックの実行（error の印と結果の一致、アニメーションが進む）、確認問題（未入力・不正解・正解・正解済み）、ステップ実行（進む・戻る・最後まで・最初から）、「CPU を見る」パネル、実験場（全サンプル、キー入力）、ページのエラー 0 件、幅 390px で横スクロールなし、を確かめる。`--shots` でライト / ダーク × 幅 1280 / 390 のスクリーンショットを撮る

エミュレータの制約：RAM は 64 KiB（.text と .data は各 32 KiB まで）、画面は 32 × 32 の 16 色、割り込みなし。1 回の実行は既定で 100 万命令まで（超えると打ち切り）。

UI は unslop（Damir Sokolovsky, CC BY 4.0, https://github.com/heydamir/unslop）のチェックリストに沿って調整。
