実験場（自由に試す）
プログラムと回路は、このサイトのために作った小さな RISC-V（RV32IM）エミュレータと論理回路シミュレータが、ブラウザの中で実行します。読み込むものはなく、すぐ動きます。

付録：早見表と用語集

このサイトの CPU の命令、機械語の形、疑似命令、レジスタ、ecall、メモリマップ、CSR と例外、アセンブラと回路記述言語の書き方、そしてこの本に出てきた用語を、引きやすい形にまとめました。

21.1命令の早見表

このサイトの CPU が実行できる命令は 56 個です。RV32I の 40 個、M 拡張（掛け算と割り算）の 8 個、CSR の命令 6 個、それに mret と wfi です。表の rd は結果を入れるレジスタ、rs1 と rs2 は読むレジスタを表します。

レジスタどうしの計算

書き方意味
add rd, rs1, rs2rd ← rs1 + rs2
sub rd, rs1, rs2rd ← rs1 − rs2
and rd, rs1, rs2rd ← rs1 と rs2 のビットごとの AND
or rd, rs1, rs2rd ← ビットごとの OR
xor rd, rs1, rs2rd ← ビットごとの XOR
sll rd, rs1, rs2rd ← rs1 を左へ（rs2 の下位 5 ビット）ビットずらす
srl rd, rs1, rs2rd ← rs1 を右へずらす。空いた上位には 0 を入れる（論理シフト）
sra rd, rs1, rs2rd ← rs1 を右へずらす。空いた上位には符号ビットを入れる（算術シフト）
slt rd, rs1, rs2rd ← rs1 < rs2 なら 1、そうでなければ 0（符号付きで比べる）
sltu rd, rs1, rs2rd ← rs1 < rs2 なら 1、そうでなければ 0（符号なしで比べる）

数（即値）との計算

書き方意味
addi rd, rs1, 数rd ← rs1 + 数
andi rd, rs1, 数rd ← rs1 と数のビットごとの AND
ori rd, rs1, 数rd ← ビットごとの OR
xori rd, rs1, 数rd ← ビットごとの XOR
slli rd, rs1, 量rd ← rs1 を左へ「量」ビットずらす（量は 0〜31）
srli rd, rs1, 量rd ← rs1 を右へずらす。上位には 0（論理シフト）
srai rd, rs1, 量rd ← rs1 を右へずらす。上位には符号ビット（算術シフト）
slti rd, rs1, 数rd ← rs1 < 数 なら 1、そうでなければ 0（符号付き）
sltiu rd, rs1, 数rd ← rs1 < 数 なら 1、そうでなければ 0（符号なし。数は符号拡張してから符号なしとして比べる）
lui rd, 数rd ← 数を 12 ビット左へずらした値（下位 12 ビットは 0）。数は 20 ビット
auipc rd, 数rd ← pc +（数を 12 ビット左へずらした値）

addi などに書ける数は -2048〜2047（12 ビット）です。それより大きな数は、疑似命令の li で先にレジスタへ入れます。

掛け算と割り算（M 拡張）

書き方意味
mul rd, rs1, rs2rd ← rs1 × rs2 の下位 32 ビット
mulh rd, rs1, rs2rd ← rs1 × rs2 の上位 32 ビット（どちらも符号付き）
mulhu rd, rs1, rs2rd ← 上位 32 ビット（どちらも符号なし）
mulhsu rd, rs1, rs2rd ← 上位 32 ビット（rs1 は符号付き、rs2 は符号なし）
div rd, rs1, rs2rd ← rs1 ÷ rs2（符号付き。0 に近いほうへ丸める）
divu rd, rs1, rs2rd ← rs1 ÷ rs2（符号なし）
rem rd, rs1, rs2rd ← rs1 ÷ rs2 の余り（符号付き。符号は rs1 と同じ）
remu rd, rs1, rs2rd ← 余り（符号なし）

0 で割っても例外にはなりません。div と divu の結果は全ビットが 1（div なら -1）、rem と remu の結果は割られる数そのものです。-2147483648 ÷ -1 は、div が -2147483648、rem が 0 になります。

メモリの読み書き（ロードとストア）

書き方意味
lw rd, ずれ(rs1)rd ← 番地 rs1 + ずれ の 4 バイト
lh rd, ずれ(rs1)rd ← 2 バイト。符号拡張する
lhu rd, ずれ(rs1)rd ← 2 バイト。上位は 0
lb rd, ずれ(rs1)rd ← 1 バイト。符号拡張する
lbu rd, ずれ(rs1)rd ← 1 バイト。上位は 0
sw rs2, ずれ(rs1)番地 rs1 + ずれ に、rs2 の 4 バイトを書く
sh rs2, ずれ(rs1)rs2 の下位 2 バイトを書く
sb rs2, ずれ(rs1)rs2 の下位 1 バイトを書く

「ずれ」は -2048〜2047 です。lw と sw は 4 の倍数、lh lhu sh は 2 の倍数の番地でなければ、例外になります。

分岐とジャンプ

書き方意味
beq rs1, rs2, ラベルrs1 = rs2 ならラベルへ飛ぶ
bne rs1, rs2, ラベルrs1 ≠ rs2 なら飛ぶ
blt rs1, rs2, ラベルrs1 < rs2 なら飛ぶ（符号付き）
bge rs1, rs2, ラベルrs1 ≥ rs2 なら飛ぶ（符号付き）
bltu rs1, rs2, ラベルrs1 < rs2 なら飛ぶ（符号なし）
bgeu rs1, rs2, ラベルrs1 ≥ rs2 なら飛ぶ（符号なし）
jal rd, ラベルrd ← 次の命令の番地（pc + 4）。そのあとラベルへ飛ぶ
jalr rd, ずれ(rs1)rd ← pc + 4。そのあと番地 rs1 + ずれ へ飛ぶ（最下位ビットは 0 にする）

条件分岐で飛べるのは前後 4 KiB まで、jal は前後 1 MiB までです。

システムと CSR

書き方意味

csrrs rd, CSR, rs1rd ← CSR の古い値。CSR のうち、rs1 で 1 のビットを 1 にする
csrrc rd, CSR, rs1rd ← CSR の古い値。CSR のうち、rs1 で 1 のビットを 0 にする

x0zeroいつも 0。書いても変わらない—
x1ra戻り先の番地呼ぶ側
x2spスタックポインタ呼ばれる側

x4tpスレッドポインタ。このサイトでは使わない—

21.5ecall

a7 に番号、a0 に値を入れて ecall を実行します。番号は、学習用のシミュレータ RARS と同じです。

a7仕事
1a0 を 10 進の整数（符号付き）で表示
4a0 の番地から始まる文字列（NUL 終端）を表示
10終了（終了コード 0）
11a0 の文字を表示
34a0 を 16 進（0x と 8 桁）で表示
35a0 を 2 進（32 桁）で表示
36a0 を符号なしの 10 進で表示
93a0 を終了コードにして終了

これ以外の番号は例外（11 番）になります。U モードで実行した ecall は、mtvec が設定されていれば、この表の仕事をせずにトラップになります（第 19 章）。

番地は 32 ビット、並べ方はリトルエンディアンです。

0x10000〜0x103FF画面。32 × 32 ピクセル、1 バイト 1 ピクセル。(x, y) は 0x10000 + y × 32 + x。値は色番号 0〜15
0x20000コンソール出力。1 バイト書くと、その文字が出る（UTF-8 のバイト列として組み立てる）

21.7CSR と例外

CSR は、csrr や csrw などの命令で、名前か番号を書いて読み書きします。M モードでだけ使えます。

CSR番号中身
mstatus0x300状態。ビット 3 が MIE、ビット 7 が MPIE、ビット 12〜11 が MPP（3 = M、0 = U）
misa0x301対応している命令セット。読むと 0x40001100（RV32IM）
mie0x304割り込みの許可。読み書きできるが、割り込みがないので何も起きない
mtvec0x305トラップの飛び先。0 なら「未設定」で、例外はエラーとして止まる。下位 2 ビットはいつも 0
mscratch0x340自由に使える 1 語
mepc0x341トラップを起こした命令の番地。下位 2 ビットはいつも 0
mcause0x342トラップの原因の番号
mtval0x343原因に関係する値（番地、機械語など）
mip0x344保留中の割り込み。読み書きできるが、何も起きない
mcycle0xb00実行した命令数
minstret0xb02実行した命令数
cycle0xc00実行した命令数（読み出し専用）
time0xc01実行した命令数（読み出し専用）
instret0xc02実行した命令数（読み出し専用）
mvendorid0xf11読むと 0（読み出し専用）
marchid0xf12読むと 0（読み出し専用）
mimpid0xf13読むと 0（読み出し専用）
mhartid0xf14読むと 0（読み出し専用）

トラップが起きたとき、CPU は次のことをします。

  1. mepc に、原因になった命令の番地を入れる
  2. mcause に原因の番号、mtval に関係する値を入れる
  3. mstatus の MPP に直前の特権モード、MPIE に直前の MIE を入れ、MIE を 0 にする
  4. M モードになり、mtvec の番地へ飛ぶ

mret は逆に、mepc の番地へ飛び、MPP のモードに移り、MIE を MPIE の値に戻します。

0命令アドレスの整列違反4 の倍数ではない番地へ飛んだ

宣言と文

書き方意味

test a=3, b=5真理値表を、指定した入力の組だけにする。-> s=8 と書くと、出力が合うかも調べる

式（上ほど先に計算する）

書き方意味
a[0]、a[3:0]バスの 1 ビット、範囲

a + b、a - b足し算、引き算（あふれた桁は捨てる）

  • reg があるか、帰還のある回路（SR ラッチなど）は、step か clock で入力を与えると、タイミング表と波形が出る
