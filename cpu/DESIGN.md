- サイト名（BRAND）：`図解 CPU`
- localStorage の接頭辞：`zc-`
- 置き場所：`docs/cpu/`（`src/` が原稿とソース、`site/` が生成物）。ビルドは `node src/build.mjs`（`docs/cpu` で実行）
- 外部依存なし（実行環境は自作なので CDN も不要）。Google Fonts だけは既存サイトと同じ

## 実行環境 1：CPU エミュレータ（`src/assets/rv.js`）

DOM を使わない中心部分（`window.RV` / Node の `globalThis.RV`）と、画面部分を分ける。Node の検査スクリプトから読み込めること。

### 機械
- 命令セット：**RV32I の全命令（fence / ecall / ebreak を含む）+ M 拡張（mul / mulh / mulhsu / mulhu / div / divu / rem / remu）**。CSR は 19 章で使う最小限（`csrrw` 系、mtvec / mepc / mcause / mstatus / mtval、`mret`）。
- レジスタ：x0〜x31（x0 は常に 0）、pc。ABI 名（zero ra sp gp tp t0-t6 s0/fp s1-s11 a0-a7）。
- メモリマップ（32 ビットアドレス、リトルエンディアン）

| アドレス | 中身 |
| --- | --- |
| `0x0000_0000`〜`0x0000_FFFF` | RAM 64 KiB。`.text` は 0x0000 から、`.data` は 0x8000 から。`sp` の初期値は 0x10000、`gp` は 0x8000 |
| `0x0001_0000`〜`0x0001_03FF` | 画面：32 × 32 ピクセル、1 バイト 1 ピクセル（下位 4 ビットが色番号 0〜15、0 = 黒）。行優先、(x, y) は `0x10000 + y*32 + x` |
| `0x0002_0000` | コンソール出力：1 バイト書くとその文字を出す（UTF-8 のバイト列として組み立てて表示） |
| `0x0002_0004` | キーボード：読むと、押されたキーのコード（なければ 0）。読んだら消える。矢印は ← 1, ↑ 2, → 3, ↓ 4、他は ASCII |
| `0x0002_0008` | 乱数：読むたびに 32 ビットの擬似乱数（シード固定可。検査で再現できるように既定は固定シード） |
| `0x0002_000C` | サイクルカウンタ（実行した命令数の下位 32 ビット） |
| `0x0002_0010` | 画面の更新：何か書くと「1 フレーム終わり」の合図（アニメーション用。実行を一時停止して描画する） |

- 範囲外のアクセス、整列していない lw / sw / lh / sh、不正な命令は例外。CSR を設定していなければ、エラーとして止まり「何番地の何という命令で、何が起きたか」を日本語で出す。
- ecall（RARS / Venus と同じ番号、a7 で選ぶ）：1 = a0 を整数で表示、4 = a0 の番地の文字列（NUL 終端）を表示、11 = a0 の文字を表示、10 = 終了、93 = a0 を終了コードとして終了、34 = a0 を 16 進で表示、35 = a0 を 2 進で表示。
- 停止条件：ecall 10/93、pc がプログラムの外（0 番地へのジャンプを除く…ではなく、`.text` の終端を越えたら終了）、命令数の上限（既定 1,000,000、無限ループ対策。超えたら「止まらないので打ち切りました」）。

### アセンブラ
- GNU as 風の構文：ラベル `loop:`、コメント `#` と `//`、`.text` `.data` `.word` `.half` `.byte` `.ascii` `.asciz` / `.string` `.space` `.align` `.globl`（無視）`.equ`。
- 数値は 10 進・`0x`・`0b`・文字 `'A'`（エスケープ `\n` など）、負数。
- 疑似命令：`li`（任意の 32 ビット値を lui + addi に展開）、`la`、`mv`、`not`、`neg`、`nop`、`j`、`jr`、`ret`、`call`、`tail`、`beqz` `bnez` `blez` `bgez` `bltz` `bgtz`、`bgt` `ble` `bgtu` `bleu`、`seqz` `snez` `sltz` `sgtz`、`jal label`（rd 省略 = ra）、`jalr rs`。
- `%hi(sym)` / `%lo(sym)`。オフセット形式 `lw t0, 8(sp)`、ラベル（`lw t0, label`）。
- エラーは行番号と日本語の理由（「3 行目：レジスタ名 `x32` はありません」など）。
- 出力：機械語（Uint32 配列）、行番号と番地の対応表（ステップ実行で今の行を光らせるため）、シンボル表。
- 逆アセンブラ：機械語 1 語 → 命令の文字列（9 章、ステップ表示で使う）。エンコードの分解（フィールドごとのビット：opcode / rd / funct3 / rs1 / rs2 / funct7 / imm）も返す（9 章の図・表示で使う）。

### 実行と観察の API（案。実装で調整してよい）
```js
const prog = RV.assemble(src);              // { ok, words, data, lineOf(pc), pcOf(line), symbols, errors:[{line, msg}] }
const m = RV.machine({ seed, maxSteps, cache, pipeline });
m.load(prog);
const r = m.run({ until: 'halt' | 'frame', limit });   // { reason: 'exit'|'limit'|'frame'|'error'|'end', exitCode, error }
m.step();                                    // 1 命令。戻り値に「何をしたか」（読み書きしたレジスタ・メモリ、分岐したか、段階の情報）
m.regs, m.pc, m.mem (Uint8Array), m.console (文字列), m.screen (Uint8Array 1024), m.stats
m.snapshot() / m.restore(s)                  // ステップを戻すため
RV.disasm(word, pc) / RV.decode(word)        // 文字列 / フィールドの分解
```
- 統計（`m.stats`）：実行した命令数、命令の種類ごとの回数。
- **パイプラインのモデル**（17 章）：古典的 5 段（IF ID EX MEM WB）。フォワーディングあり / なしを選べる。ロード使用ハザードで 1 サイクル停止、分岐は「常に成立しないと予測」で成立時に 2 サイクルのペナルティ（または 1 ビット / 2 ビット予測器を選べる）。結果としてサイクル数、CPI、停止の内訳を出す。最初の N 命令の「パイプライン図」（命令 × サイクルの表）を作るためのデータも返す。
- **キャッシュのモデル**（18 章）：データアクセス（load/store）に対して、容量・ブロックサイズ・連想度（1 = ダイレクトマップ）・置き換え（LRU）を設定してヒット / ミスを数える。ミスのペナルティを仮に決めてサイクルに足す。アクセスの履歴（番地、セット番号、ヒットか）を返す。
- 乱数は既定で固定シード。同じプログラムは毎回同じ結果になる（採点の再現性のため）。

## 実行環境 2：論理回路シミュレータ（`src/assets/logic.js`）

小さな回路記述言語。DOM を使わない中心部分（`window.LOGIC` / `globalThis.LOGIC`）と画面部分を分ける。

```
# 半加算器
in a, b
out s, c
s = a xor b
c = a and b
```
- 演算子：`and` `or` `not` `xor` `nand` `nor` `xnor`（関数形 `nand(a, b)` も可）、括弧。`&` `|` `~` `^` も同義。
- 多ビット：`in a[4]` で 4 ビットのバス、`a[0]`（最下位）、`a[3:0]`、連結 `{a, b}`。真理値表ではバスを 10 進（と 2 進）で表示。
- 部品：
```
def ha(a, b) -> (s, c) {
  s = a xor b
  c = a and b
}
in x, y, z
out sum, carry
s1, c1 = ha(x, y)
sum, c2 = ha(s1, z)
carry = c1 or c2
```
- 組み合わせ回路の出力：全入力の真理値表（入力が多すぎる（合計 10 ビット超）ときは `test` 行で指定した組だけ）。`test a=3, b=5` で特定の入力だけ評価できる。
- 順序回路（7 章）：`reg q[4] = d`（クロックの立ち上がりで d を取り込む D フリップフロップ。初期値 0）。帰還のある組み合わせ回路（SR ラッチ）は、ゲート遅延 1 単位で値が落ち着くまで回す（発振したら「落ち着きません」）。入力の時系列を `clock 8` や `step a=1, b=0` の並びで与え、タイミング表（各ステップの全信号の値）を出す。波形の描画用データも返す。
- ゲートの数を数える（「NAND を何個使ったか」の問題用）。
- エラーは行番号と日本語の理由。

## 図エンジンの追加（`src/lib/diagrams.mjs`）

- `circuit`：ゲート記号（AND / OR / NOT / XOR / NAND / NOR、D フリップフロップの箱、マルチプレクサの台形）と配線の図。spec は `graph` と同じくグリッド座標で手書きする形でよい（自動配置はしない）。
- `wave`：タイミング図（クロック、信号の 0/1、バスの値）。
- `pipe`：パイプライン図（命令 × サイクルのマス目、段階名、停止は斜線）。
- 既存の `layout`（バイト列）は、命令のエンコード（ビットフィールド）とメモリの図にそのまま使える。
- 色はすべて CSS クラス経由（ライト / ダーク）。

## 画面（`build.mjs`、`src/assets/`）
