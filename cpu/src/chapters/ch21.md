## 命令の早見表 {#insn}

このサイトの CPU が実行できる命令は 56 個です。RV32I の 40 個、M 拡張（掛け算と割り算）の 8 個、CSR の命令 6 個、それに `mret` と `wfi` です。表の `rd` は結果を入れるレジスタ、`rs1` と `rs2` は読むレジスタを表します。

### レジスタどうしの計算

| 書き方 | 意味 |
| --- | --- |
| `add rd, rs1, rs2` | rd ← rs1 + rs2 |
| `sub rd, rs1, rs2` | rd ← rs1 − rs2 |
| `and rd, rs1, rs2` | rd ← rs1 と rs2 のビットごとの AND |
| `or rd, rs1, rs2` | rd ← ビットごとの OR |
| `xor rd, rs1, rs2` | rd ← ビットごとの XOR |
| `sll rd, rs1, rs2` | rd ← rs1 を左へ（rs2 の下位 5 ビット）ビットずらす |
| `srl rd, rs1, rs2` | rd ← rs1 を右へずらす。空いた上位には 0 を入れる（論理シフト） |
| `sra rd, rs1, rs2` | rd ← rs1 を右へずらす。空いた上位には符号ビットを入れる（算術シフト） |
| `slt rd, rs1, rs2` | rd ← rs1 < rs2 なら 1、そうでなければ 0（符号付きで比べる） |
| `sltu rd, rs1, rs2` | rd ← rs1 < rs2 なら 1、そうでなければ 0（符号なしで比べる） |

### 数（即値）との計算

| 書き方 | 意味 |
| --- | --- |
| `addi rd, rs1, 数` | rd ← rs1 + 数 |
| `andi rd, rs1, 数` | rd ← rs1 と数のビットごとの AND |
| `ori rd, rs1, 数` | rd ← ビットごとの OR |
| `xori rd, rs1, 数` | rd ← ビットごとの XOR |
| `slli rd, rs1, 量` | rd ← rs1 を左へ「量」ビットずらす（量は 0〜31） |
| `srli rd, rs1, 量` | rd ← rs1 を右へずらす。上位には 0（論理シフト） |
| `srai rd, rs1, 量` | rd ← rs1 を右へずらす。上位には符号ビット（算術シフト） |
| `slti rd, rs1, 数` | rd ← rs1 < 数 なら 1、そうでなければ 0（符号付き） |
| `sltiu rd, rs1, 数` | rd ← rs1 < 数 なら 1、そうでなければ 0（符号なし。数は符号拡張してから符号なしとして比べる） |
| `lui rd, 数` | rd ← 数を 12 ビット左へずらした値（下位 12 ビットは 0）。数は 20 ビット |
| `auipc rd, 数` | rd ← pc +（数を 12 ビット左へずらした値） |

`addi` などに書ける数は -2048〜2047（12 ビット）です。それより大きな数は、疑似命令の `li` で先にレジスタへ入れます。

### 掛け算と割り算（M 拡張）

| 書き方 | 意味 |
| --- | --- |
| `mul rd, rs1, rs2` | rd ← rs1 × rs2 の下位 32 ビット |
| `mulh rd, rs1, rs2` | rd ← rs1 × rs2 の上位 32 ビット（どちらも符号付き） |
| `mulhu rd, rs1, rs2` | rd ← 上位 32 ビット（どちらも符号なし） |
| `mulhsu rd, rs1, rs2` | rd ← 上位 32 ビット（rs1 は符号付き、rs2 は符号なし） |
| `div rd, rs1, rs2` | rd ← rs1 ÷ rs2（符号付き。0 に近いほうへ丸める） |
| `divu rd, rs1, rs2` | rd ← rs1 ÷ rs2（符号なし） |
| `rem rd, rs1, rs2` | rd ← rs1 ÷ rs2 の余り（符号付き。符号は rs1 と同じ） |
| `remu rd, rs1, rs2` | rd ← 余り（符号なし） |

0 で割っても例外にはなりません。`div` と `divu` の結果は全ビットが 1（`div` なら -1）、`rem` と `remu` の結果は割られる数そのものです。-2147483648 ÷ -1 は、`div` が -2147483648、`rem` が 0 になります。

### メモリの読み書き（ロードとストア）

| 書き方 | 意味 |
| --- | --- |
| `lw rd, ずれ(rs1)` | rd ← 番地 rs1 + ずれ の 4 バイト |
| `lh rd, ずれ(rs1)` | rd ← 2 バイト。符号拡張する |
| `lhu rd, ずれ(rs1)` | rd ← 2 バイト。上位は 0 |
| `lb rd, ずれ(rs1)` | rd ← 1 バイト。符号拡張する |
| `lbu rd, ずれ(rs1)` | rd ← 1 バイト。上位は 0 |
| `sw rs2, ずれ(rs1)` | 番地 rs1 + ずれ に、rs2 の 4 バイトを書く |
| `sh rs2, ずれ(rs1)` | rs2 の下位 2 バイトを書く |
| `sb rs2, ずれ(rs1)` | rs2 の下位 1 バイトを書く |

「ずれ」は -2048〜2047 です。`lw` と `sw` は 4 の倍数、`lh` `lhu` `sh` は 2 の倍数の番地でなければ、例外になります。

### 分岐とジャンプ

| 書き方 | 意味 |
| --- | --- |
| `beq rs1, rs2, ラベル` | rs1 = rs2 ならラベルへ飛ぶ |
| `bne rs1, rs2, ラベル` | rs1 ≠ rs2 なら飛ぶ |
| `blt rs1, rs2, ラベル` | rs1 < rs2 なら飛ぶ（符号付き） |
| `bge rs1, rs2, ラベル` | rs1 ≥ rs2 なら飛ぶ（符号付き） |
| `bltu rs1, rs2, ラベル` | rs1 < rs2 なら飛ぶ（符号なし） |
| `bgeu rs1, rs2, ラベル` | rs1 ≥ rs2 なら飛ぶ（符号なし） |
| `jal rd, ラベル` | rd ← 次の命令の番地（pc + 4）。そのあとラベルへ飛ぶ |
| `jalr rd, ずれ(rs1)` | rd ← pc + 4。そのあと番地 rs1 + ずれ へ飛ぶ（最下位ビットは 0 にする） |

条件分岐で飛べるのは前後 4 KiB まで、`jal` は前後 1 MiB までです。

### システムと CSR

| 書き方 | 意味 |
| --- | --- |
| `ecall` | 環境（OS やこのサイトの機械）に仕事を頼む。番号は a7 |
| `ebreak` | ブレークポイント。mtvec が未設定なら、そこで実行を止める |
| `mret` | トラップから戻る。pc ← mepc、特権モード ← mstatus の MPP |
| `csrrw rd, CSR, rs1` | rd ← CSR の古い値。CSR ← rs1 |
| `csrrs rd, CSR, rs1` | rd ← CSR の古い値。CSR のうち、rs1 で 1 のビットを 1 にする |
| `csrrc rd, CSR, rs1` | rd ← CSR の古い値。CSR のうち、rs1 で 1 のビットを 0 にする |
| `csrrwi rd, CSR, 数` | csrrw と同じ。rs1 の代わりに 0〜31 の数を使う |
| `csrrsi rd, CSR, 数` | csrrs と同じ。数は 0〜31 |
| `csrrci rd, CSR, 数` | csrrc と同じ。数は 0〜31 |
| `wfi` | 割り込みを待つ。このサイトの機械では何もしない |
| `fence` | メモリの読み書きの順序を確定する。このサイトの機械では何もしない |

## 疑似命令 {#pseudo}

疑似命令は、アセンブラが本物の命令に置き換える別名です。機械語になったあとは、本物の命令と区別がつきません。

| 書き方 | 展開される命令 |
| --- | --- |
| `nop` | `addi zero, zero, 0` |
| `li rd, 数` | `addi rd, zero, 数`（数が -2048〜2047 のとき）／ `lui rd, 上位` + `addi rd, rd, 下位`（それ以外。下位 12 ビットが 0 なら `lui` だけ） |
| `la rd, ラベル` | `lui rd, %hi(ラベル)` + `addi rd, rd, %lo(ラベル)` |
| `mv rd, rs` | `addi rd, rs, 0` |
| `not rd, rs` | `xori rd, rs, -1` |
| `neg rd, rs` | `sub rd, zero, rs` |
| `seqz rd, rs` | `sltiu rd, rs, 1` |
| `snez rd, rs` | `sltu rd, zero, rs` |
| `sltz rd, rs` | `slt rd, rs, zero` |
| `sgtz rd, rs` | `slt rd, zero, rs` |
| `sgt rd, rs, rt` | `slt rd, rt, rs` |
| `sgtu rd, rs, rt` | `sltu rd, rt, rs` |
| `beqz rs, ラベル` | `beq rs, zero, ラベル` |
| `bnez rs, ラベル` | `bne rs, zero, ラベル` |
| `blez rs, ラベル` | `bge zero, rs, ラベル` |
| `bgez rs, ラベル` | `bge rs, zero, ラベル` |
| `bltz rs, ラベル` | `blt rs, zero, ラベル` |
| `bgtz rs, ラベル` | `blt zero, rs, ラベル` |
| `bgt rs, rt, ラベル` | `blt rt, rs, ラベル` |
| `ble rs, rt, ラベル` | `bge rt, rs, ラベル` |
| `bgtu rs, rt, ラベル` | `bltu rt, rs, ラベル` |
| `bleu rs, rt, ラベル` | `bgeu rt, rs, ラベル` |
| `j ラベル` | `jal zero, ラベル` |
| `jal ラベル` | `jal ra, ラベル` |
| `jr rs` | `jalr zero, 0(rs)` |
| `jalr rs` | `jalr ra, 0(rs)` |
| `ret` | `jalr zero, 0(ra)` |
| `call ラベル` | `jal ra, ラベル` |
| `tail ラベル` | `jal zero, ラベル` |
| `lw rd, ラベル` | `lui rd, %hi(ラベル)` + `lw rd, %lo(ラベル)(rd)`（`lb` `lh` `lbu` `lhu` も同じ） |
| `sw rs, ラベル, rt` | `lui rt, %hi(ラベル)` + `sw rs, %lo(ラベル)(rt)`（`sb` `sh` も同じ） |
| `csrr rd, csr` | `csrrs rd, csr, zero` |
| `csrw csr, rs` | `csrrw zero, csr, rs` |
| `csrs csr, rs` | `csrrs zero, csr, rs` |
| `csrc csr, rs` | `csrrc zero, csr, rs` |
| `csrwi csr, 数` | `csrrwi zero, csr, 数` |
| `csrsi csr, 数` | `csrrsi zero, csr, 数` |
| `csrci csr, 数` | `csrrci zero, csr, 数` |

`la`、大きな数の `li`、ラベルを直接書く `lw` と `sw` は 2 命令になります。それ以外は 1 命令です。

## レジスタ {#regs}

x0〜x31 の 32 本で、どれも 32 ビットです。ふだんは ABI 名（役割で付けた別名）で書きます。

| 番号 | ABI 名 | 用途 | 関数呼び出しで値を守る側 |
| --- | --- | --- | --- |
| x0 | `zero` | いつも 0。書いても変わらない | — |
| x1 | `ra` | 戻り先の番地 | 呼ぶ側 |
| x2 | `sp` | スタックポインタ | 呼ばれる側 |
| x3 | `gp` | グローバルポインタ。このサイトでは 0x8000 が入っている | — |
| x4 | `tp` | スレッドポインタ。このサイトでは使わない | — |
| x5〜x7 | `t0`〜`t2` | 一時的な値 | 呼ぶ側 |
| x8 | `s0`（`fp`） | 保存されるレジスタ。フレームポインタにも使う | 呼ばれる側 |
| x9 | `s1` | 保存されるレジスタ | 呼ばれる側 |
| x10〜x11 | `a0`〜`a1` | 引数と戻り値 | 呼ぶ側 |
| x12〜x17 | `a2`〜`a7` | 引数。a7 は ecall の番号にも使う | 呼ぶ側 |
| x18〜x27 | `s2`〜`s11` | 保存されるレジスタ | 呼ばれる側 |
| x28〜x31 | `t3`〜`t6` | 一時的な値 | 呼ぶ側 |

- 「呼ぶ側」が守るレジスタは、関数を呼ぶと壊れる前提で使う。あとで要る値は、呼ぶ前に自分で保存する
- 「呼ばれる側」が守るレジスタは、関数の中で使うなら保存して、戻る前に元に戻す
- このサイトの機械は、実行を始めるとき `sp` に 0x10000、`gp` に 0x8000、`ra` に「プログラムの終わり」の番地を入れる。`main` から `ret` すると終わるのはこのため

## ecall {#ecall}

`a7` に番号、`a0` に値を入れて `ecall` を実行します。番号は、学習用のシミュレータ RARS と同じです。

| a7 | 仕事 |
| --- | --- |
| 1 | `a0` を 10 進の整数（符号付き）で表示 |
| 4 | `a0` の番地から始まる文字列（NUL 終端）を表示 |
| 10 | 終了（終了コード 0） |
| 11 | `a0` の文字を表示 |
| 34 | `a0` を 16 進（0x と 8 桁）で表示 |
| 35 | `a0` を 2 進（32 桁）で表示 |
| 36 | `a0` を符号なしの 10 進で表示 |
| 93 | `a0` を終了コードにして終了 |

これ以外の番号は例外（11 番）になります。U モードで実行した `ecall` は、`mtvec` が設定されていれば、この表の仕事をせずにトラップになります（第 19 章）。

## CSR と例外 {#csr}

CSR は、`csrr` や `csrw` などの命令で、名前か番号を書いて読み書きします。M モードでだけ使えます。

| CSR | 番号 | 中身 |
| --- | --- | --- |
| `mstatus` | `0x300` | 状態。ビット 3 が MIE、ビット 7 が MPIE、ビット 12〜11 が MPP（3 = M、0 = U） |
| `misa` | `0x301` | 対応している命令セット。読むと `0x40001100`（RV32IM） |
| `mie` | `0x304` | 割り込みの許可。読み書きできるが、割り込みがないので何も起きない |
| `mtvec` | `0x305` | トラップの飛び先。0 なら「未設定」で、例外はエラーとして止まる。下位 2 ビットはいつも 0 |
| `mscratch` | `0x340` | 自由に使える 1 語 |
| `mepc` | `0x341` | トラップを起こした命令の番地。下位 2 ビットはいつも 0 |
| `mcause` | `0x342` | トラップの原因の番号 |
| `mtval` | `0x343` | 原因に関係する値（番地、機械語など） |
| `mip` | `0x344` | 保留中の割り込み。読み書きできるが、何も起きない |
| `mcycle` | `0xb00` | 実行した命令数 |
| `minstret` | `0xb02` | 実行した命令数 |
| `cycle` | `0xc00` | 実行した命令数（読み出し専用） |
| `time` | `0xc01` | 実行した命令数（読み出し専用） |
| `instret` | `0xc02` | 実行した命令数（読み出し専用） |
| `mvendorid` | `0xf11` | 読むと 0（読み出し専用） |
| `marchid` | `0xf12` | 読むと 0（読み出し専用） |
| `mimpid` | `0xf13` | 読むと 0（読み出し専用） |
| `mhartid` | `0xf14` | 読むと 0（読み出し専用） |

トラップが起きたとき、CPU は次のことをします。

1. `mepc` に、原因になった命令の番地を入れる
2. `mcause` に原因の番号、`mtval` に関係する値を入れる
3. `mstatus` の MPP に直前の特権モード、MPIE に直前の MIE を入れ、MIE を 0 にする
4. M モードになり、`mtvec` の番地へ飛ぶ

`mret` は逆に、`mepc` の番地へ飛び、MPP のモードに移り、MIE を MPIE の値に戻します。

| mcause | 名前 | このサイトの機械で起きるとき |
| --- | --- | --- |
| 0 | 命令アドレスの整列違反 | 4 の倍数ではない番地へ飛んだ |
| 1 | 命令アクセス違反 | pc が RAM（0x0000〜0xFFFF）の外に出た |
| 2 | 不正な命令 | 命令として解釈できない数を実行した。U モードで CSR 命令や `mret` を実行した。ない CSR を使った |
| 3 | ブレークポイント | `ebreak` を実行した（`mtvec` を設定してあるとき） |
| 4 | ロードの整列違反 | `lw` `lh` `lhu` で、そろっていない番地を読んだ |
| 5 | ロードのアクセス違反 | メモリも入出力もない番地を読んだ |
| 6 | ストアの整列違反 | `sw` `sh` で、そろっていない番地に書いた |
| 7 | ストアのアクセス違反 | メモリも入出力もない番地に書いた |
| 8 | U モードからの ecall | U モードで `ecall` を実行した（`mtvec` を設定してあるとき） |
| 11 | M モードからの ecall | M モードで、知らない番号の `ecall` を実行した |

このサイトの機械には、割り込み（タイマーなど）、メモリの保護、仮想メモリ、S モードはありません。

## アセンブラの書き方 {#asm}

| 書き方 | 意味 |
| --- | --- |
| `loop:` | ラベル。その場所の番地に名前を付ける |
| `1:` と `1b`、`1f` | 数字のラベル。`1b` は手前の、`1f` は先の `1:` を指す |
| `# …`、`// …` | コメント |
| `.text` | ここから命令（0x0000 番地から置かれる） |
| `.data` | ここからデータ（0x8000 番地から置かれる）。命令は書けない |
| `.word 1, 2` | 4 バイトの数を並べる。4 の倍数の番地に自動でそろう |
| `.half 1, 2` | 2 バイトの数。2 の倍数の番地にそろう |
| `.byte 1, 2` | 1 バイトの数 |
| `.ascii "ab"` | 文字列（終わりの 0 なし） |
| `.asciz "ab"`、`.string "ab"` | 文字列（終わりに 0 を付ける） |
| `.space 16` | 0 を 16 バイト |
| `.align 2` | 次の番地を 2 の 2 乗（4）の倍数にそろえる |
| `.equ N, 10` | 定数に名前を付ける（`N = 10` とも書ける） |
| `%hi(ラベル)`、`%lo(ラベル)` | 番地の上位 20 ビットと下位 12 ビット。`lui` と `addi` の組に使う |

- 数は、10 進（`42`、`-7`）、16 進（`0x2a`）、2 進（`0b101010`）、文字（`'A'`、`'\n'`）で書ける。`+ - * / & | ^ ~ << >>` と括弧の式も書ける
- メモリの番地は `8(sp)`、`(a0)`、`%lo(ラベル)(t0)` の形で書く
- 実行は、ラベル `_start` があればそこから、なければ `main` から、どちらもなければ 0 番地から始まる
- `ecall` の 10 番か 93 番を実行するか、命令の並びの最後まで来ると終わる。1,000,000 命令を実行しても終わらなければ、打ち切られる

## 回路記述言語 {#logic}

第 4〜7 章で使った、回路を書く言語の要約です。

```logic run title="部品（def）を使った全加算器"
def ha(a, b) -> (s, c) {
  s = a xor b
  c = a and b
}
in x, y, z
out sum, carry
s1, c1 = ha(x, y)
sum, c2 = ha(s1, z)
carry = c1 or c2
```

### 宣言と文

| 書き方 | 意味 |
| --- | --- |
| `in a, b` | 入力。`in a[4]` は 4 ビットのバス（`a[0]` が最下位） |
| `out s, c` | 出力 |
| `s = a xor b` | 線に名前を付ける。行の順番は自由。1 つの線に値を入れられるのは 1 回だけ |
| `wire c[5]` | 途中の線の幅を先に決める。`c[1] = …` と 1 ビットずつ入れるときに使う |
| `def 名前(a, b) -> (s, c) { … }` | 部品を作る。使うときは `s, c = 名前(x, y)`。使わない出力は `_` で捨てる |
| `reg q[4] = d` | D フリップフロップ。クロックの立ち上がりで `d` を取り込む。最初は 0（`init 1` で変えられる） |
| `test a=3, b=5` | 真理値表を、指定した入力の組だけにする。`-> s=8` と書くと、出力が合うかも調べる |
| `step a=1` | 入力を変えて 1 行記録する（タイミング表）。書かなかった入力は前のまま |
| `clock 8` | `step` を 8 回 |
| `# …`、`// …` | コメント |

### 式（上ほど先に計算する）

| 書き方 | 意味 |
| --- | --- |
| `a[0]`、`a[3:0]` | バスの 1 ビット、範囲 |
| `not a`（`~a`、`!a`） | 反転 |
| `a + b`、`a - b` | 足し算、引き算（あふれた桁は捨てる） |
| `a and b`、`a nand b`（`&`） | AND、NAND |
| `a xor b`、`a xnor b`（`^`） | XOR、XNOR |
| `a or b`、`a nor b`（`\|`） | OR、NOR |
| `a == b` | 等しければ 1 |
| `and(a, b, c)`、`nand(a, b)` など | 関数の形。入力が 3 つ以上のゲートも書ける |
| `mux(s, a, b)` | `s` が 0 なら `a`、1 なら `b`。`s` が 2 ビットなら `mux(s, a, b, c, d)` |
| `{a, b}` | 連結。左が上位 |
| `0`、`1`、`10`、`0b1010`、`0x1f` | 数。2 進は 1 桁 1 ビット、16 進は 1 桁 4 ビットの幅になる |

- バスどうしの演算は、ビットごとに行う。片方が 1 ビットなら、全ビットに配られる
- 何も指定しなければ、入力のすべての組み合わせの真理値表が出る（入力の合計が 10 ビットまで）
- `reg` があるか、帰還のある回路（SR ラッチなど）は、`step` か `clock` で入力を与えると、タイミング表と波形が出る
