はじめに：合格メソッド

LinuC レベル2 の試験の形、出題範囲と重要度、レベル1 からどこが広がるか。診断 → 学ぶ → 解く → 模試の 4 段階の進め方と、8 週間の計画、練習問題の使い方をまとめます。

0.1この本について

この本は、LinuC（リナック）レベル2 に合格するための学習書です。レベル1 の対策の 図解 LinuC と、その前の 図解 Linux を読み終えた人を前提にしています。全部を覚えている必要はありません。前提になる所には、各章からリンクで戻れます。

レベル1 とレベル2 は、問われる立場が違います。

レベル1（図解 LinuC）レベル2（この本）
立場1 台の Linux を使い、管理するサーバーを立て、ほかの機械にサービスを出す
中心コマンドとオプション、ファイルの場所サーバーの設定ファイル、管理コマンド、障害の切り分け
範囲1 台の中（ファイル、プロセス、パッケージ、ネットワークの基本）カーネル、ストレージ、仮想化とコンテナ、DNS・Web・メール・ファイル共有、セキュリティ、システムの設計
聞き方「このコマンドは何をするか」「この設定の説明として正しいものは」「空欄に入るディレクティブは」

レベル2 では、設定ファイルの抜粋を見せて問う問題が増えます。named.conf の allow-transfer、Apache の <VirtualHost>、smb.conf の [homes]、sshd_config の PermitRootLogin のように、ディレクティブの名前と書き方を正しく覚えることが大事です。この本は、設定ファイルを Docker の中で実際に動かし、検査コマンド（named-checkconf、apachectl -t、nginx -t、testparm など）を通したものを載せています。

メモ問題はこのサイトのオリジナルです

練習問題と模擬試験は、出題範囲をもとにこのサイトが作ったものです。本番の問題を写したものではありません。形（選択肢の数、「2 つ選択してください」、入力する問題）は、本番に近づけてあります。

0.2試験の形

LinuC レベル2 に認定されるには、201 試験と 202 試験の両方に合格します。どちらから受けてもかまいません。

項目内容
問題の数1 回約 60 問
時間90 分（そのうち 5 分は、試験の後のアンケート。解く時間は実質 85 分）
形コンピュータで受ける（CBT）。ほとんどはマウスで選ぶ問題で、キーボードで入力する問題が少しある
受験料1 回 16,500 円（税込）
受ける条件なし（レベル1 を持っていなくても受けられる）
認定の条件201 と 202 の両方に 5 年以内に合格し、レベル1 の認定を持っている
合格点公表されていない

60 問を 85 分で解くので、1 問にかけられるのは 1 分 25 秒ほどです。設定ファイルを読む問題は時間がかかります。迷った問題に印を付けて先へ進み、最後に戻ります。

合格点は公表されていません。この本の模擬試験では、80% 以上を 3 回続けて取ることを目標にします。

注意申し込む前に、公式のページを確かめる

受験料、試験の形、出題範囲は変わることがあります。上の表は、この本を書いたとき（2026 年 11 月）に LinuC の公式サイト で確かめたものです。申し込む前に、もう一度公式のページを見てください。

0.3出題範囲と重要度

出題範囲（Version 10.0）は、13 の主題（2.01〜2.13）に分かれています。1〜6 が 201 試験、7〜13 が 202 試験です。各主題の下の細かい項目に重要度が付いていて、各試験で合計 60 です。問題の数が約 60 なので、重要度は、だいたい出る問題の数だと考えてかまいません。

201 では「保守と運用管理」（ソースからのビルド、バックアップ、監視、Ansible）と「起動とカーネル」で半分です。202 では「セキュリティ」と「Web とプロキシ」が重く、サーバーの種類が多いのが特徴です。細かい項目で重要度 4 の重いものは、2.01.1 ブートと GRUB、2.02.2 ファイルシステムの管理、2.04.6 Ansible、2.11.1 Samba、2.12.2 OpenSSH サーバー の 5 つです。

0.4レベル1 で学んだこと、ここで学ぶこと

レベル2 の主題は、レベル1 の主題を深めたものと、新しく出てくるサーバーとに分かれます。

主題前提になる所この本で足すこと
2.01 起動とカーネル図解 LinuC 1 章 起動と systemd、5 章 カーネルモジュール、図解 Linux 17 章GRUB の設定と再生成、UEFI と efibootmgr、unit ファイルの置き場所の優先順位、カーネルのビルド、sysctl、udev
2.02 ファイルシステムとストレージ図解 LinuC 5 章 LVM・mkfs・fstabtune2fs・dumpe2fs、XFS の道具、Btrfs のスナップショット、LVM のスナップショットと拡張、SMART
2.03 ネットワーク構成図解 LinuC 7 章無線（iw）、IP フォワーディング、tcpdump・nmap、ルーティングと障害の切り分け
2.04 保守と運用管理図解 LinuC 2 章 tar と圧縮configure と make、patch、バックアップの種類と道具、sar・vmstat・iostat、監視ツール、Ansible
2.05・2.06 仮想化とコンテナ図解 LinuC 1 章 仮想マシンとコンテナ、図解 Linux 19 章KVM と QEMU、libvirt、virt-install、virtio、Dockerfile とイメージの管理
2.07 DHCP・PAM・LDAP図解 LinuC 8 章 アカウント管理dhcpd.conf、PAM の 4 つの型と制御フラグ、LDIF と ldap* コマンド、slapd
2.08 DNS図解 LinuC 7 章 resolv.conf と dignamed.conf、ゾーンファイルとリソースレコード、rndc、DNSSEC と TSIG
2.09 Web とプロキシ図解 Linux 16 章 HTTPApache と nginx の設定、HTTPS と証明書、Squid の acl
2.10 メール図解 LinuC 9 章 MTA の基本Postfix の main.cf と master.cf、Dovecot
2.11 Samba・NFS図解 LinuC 5 章 mountsmb.conf と Samba のコマンド、/etc/exports と exportfs
2.12 セキュリティ図解 LinuC 10 章iptables のチェインとターゲット、firewall-cmd、sshd_config、OpenVPN、fail2ban・IDS
2.13 システムアーキテクチャなし稼働率・MTBF・MTTR、RPO と RTO、スケールアウト、クラウドの構成、三層構成

いちばん新しく覚えることが多いのは 202 のサーバー（2.07〜2.11）です。サーバーごとに設定ファイルの名前、主なディレクティブ、検査と再読み込みのコマンドを表にまとめて覚えます。

0.5合格メソッド：診断 → 学ぶ → 解く → 模試

  1. 診断：最初に模擬試験を 1 回受けます。点数は気にしません。採点の後に出る「主題ごとの正答率」を見て、低い主題を 2〜3 個選びます
  2. 学ぶ：選んだ主題の章を読みます。設定ファイルは、ディレクティブの表を声に出して読むくらいに繰り返します
  3. 解く：章の最後の練習問題を解きます。まちがえた問題は記録され、苦手を解くのページに集まります
  4. 模試：もう一度模擬試験を受けます。70% に届かない主題が残っていたら、2 に戻ります。80% 以上を 3 回続けて取れたら、本番を予約します
コツサーバーは「設定ファイル・検査・再読み込み」の 3 点で覚える

202 のサーバーは種類が多いので、どれも同じ形で整理します。たとえば BIND なら、設定ファイルは named.conf、検査は named-checkconf と named-checkzone、再読み込みは rndc reload です。Apache なら httpd.conf（Debian 系は apache2.conf）、apachectl -t、apachectl graceful です。各章の表は、この 3 点をそろえてあります。

0.68 週間の計画

1 日 1 時間ほどで、201 と 202 を続けて受ける計画の例です。

週やること目安
1 週目序章、201 の模試で診断。2.01（起動とカーネル）レベル1 の起動と systemd を復習しながら
2 週目2.02（ファイルシステムとストレージ）、2.03（ネットワーク構成）コマンドとオプションの表
3 週目2.04（保守と運用管理）。Ansible は Playbook を読めるまで重要度 16 でいちばん重い
4 週目2.05・2.06（仮想化とコンテナ）、苦手の復習、201 の模試80% を 3 回で 201 を予約
5 週目202 の模試で診断。2.07（DHCP・PAM・LDAP）、2.08（DNS）ゾーンファイルは手で書いてみる
6 週目2.09（Web とプロキシ）、2.10（メール）Apache と nginx の書き方の違い
7 週目2.11（Samba・NFS）、2.12（セキュリティ）iptables のチェインの図
8 週目2.13（システムアーキテクチャ）、苦手の復習、202 の模試稼働率の計算を手で。80% を 3 回で 202 を予約

2 つの合格は、5 年以内であれば認定されます。レベル1 の認定がまだなら、先にそちらを取ってください（受験の順番は自由ですが、レベル2 の認定はレベル1 の認定の後です）。

0.7練習問題の使い方

練習問題は 3 つの形です。

  • 1 つ選ぶ：ラジオボタン
  • 複数選ぶ：チェックボックス。本番と同じく「2 つ選択してください」のように、選ぶ数を問題文に書きます
  • 入力する：コマンド、ディレクティブ、ファイルの名前をキーボードで入力します。綴りが完全に合っていないと不正解です

試しに解いてみてください。

2.12.2-91

OpenSSH サーバーで、root ユーザーが SSH で直接ログインすることを禁止したい。/etc/ssh/sshd_config に書く設定として正しいものはどれか。

2.08.2-91複数選択

DNS のゾーンファイルで、名前から IP アドレスを引くためのリソースレコードを 2 つ選択してください。

2.02.3-91入力

LVM で、パーティション /dev/sdb1 を物理ボリューム（PV）として初期化する。空欄に入るコマンドを入力してください。

# ____ /dev/sdb1

答えると、正解と解説が出ます。解いた結果はこのブラウザに記録され、ページを開き直すと「前回：正解」「前回：不正解」の印が付きます。

要点まとめ
  • LinuC レベル2 は 201 と 202 の 2 つの試験。1 回約 60 問・90 分。認定にはレベル1 の認定も要る。合格点は公表されていないので、模試で 80% を目指す
  • 重要度の合計は各試験 60。重要度はだいたい出る問題の数
  • 201 は「保守と運用管理」と「起動とカーネル」が重い。202 は「セキュリティ」と「Web とプロキシ」が重い
  • 202 のサーバーは、設定ファイル・検査・再読み込みの 3 点で整理して覚える
  • 進め方は、診断 → 学ぶ → 解く → 模試の輪。苦手の主題に戻って回す
