# 図解 LinuC レベル2

LinuC レベル2（Version 10.0、201 / 202 試験）に合格するための学習書。レベル1 対策の [図解 LinuC](../linuc/) と [図解 Linux](../linux/) を読み終えた人が、試験の出題範囲を主題ごとに埋めていく。序章（試験の形、出題範囲と重要度、レベル1 との対応、合格メソッド、8 週間の計画）+ 主題ごとの 13 章 + 練習問題の復習と模擬試験のページ。

## 読む

`site/index.html` をブラウザで開く。サーバは不要で、読み込むものもない（フォントだけ Google Fonts）。

- **合格メソッド**：診断（模擬試験）→ 学ぶ（章を読む）→ 解く（章末の練習問題と「苦手を解く」）→ 模試（80% を 3 回）
- **章**：出題範囲の 1 つの主題（2.01〜2.13）が 1 章。細かい項目（2.XX.Y）ごとの解説、覚えることの表、図解 Linux の対応する節へのリンク、章末の練習問題。コマンドの例は、図解 Linux と同じ「小さな Linux」でその場で実行できる。サーバー（BIND、Apache、nginx、Squid、Postfix、Dovecot、Samba、NFS、OpenLDAP、sshd など）の設定は、Docker の Debian 12 / Rocky Linux 9 に入れて検査コマンドを通したものを、実行しない例で見せる
- **練習問題**：1 つ選ぶ・複数選ぶ・入力するの 3 つの形。答えると正解と解説（ほかの選択肢がなぜ違うかまで）が出る。解いた記録はブラウザ（localStorage の `zv-ans`）に残り、ページを開き直すと「前回：正解 / 不正解」の印が付く
- **苦手を解く**（`site/review.html`）：前回まちがえた問題、まだ解いていない問題、主題ごとの問題を 20 問ずつ出す。主題ごとの正答率（70% 未満に色）と模試の記録
- **模擬試験**（`site/mock.html`）：201 / 202 を 60 問・90 分。主題ごとに重要度の数だけ問題を選ぶ（まだ解いていない問題が先）。採点すると主題ごとの正答率と全問の解説
- 問題はこのサイトのオリジナルで、本番の問題ではない

## 編集・ビルド

```console
$ node src/build.mjs              # docs/linuc で実行
$ ZV_CHECK=1 node src/build.mjs   # 原稿と練習問題の形だけを確かめる（site/ に書かない）
```

図解 LinuC（レベル1）の build.mjs と qa.js、図解 Linux の小さな Linux（`src/assets/kernel.js` ほか、`src/lib/lnx-files.mjs`）をそのまま使い、次を足した：

| パス | 内容 |
| --- | --- |
| `src/build.mjs` の `TOPICS` | 出題範囲（主題、細かい項目、重要度、試験）。LPI-Japan の公開している出題範囲から |
| `src/build.mjs` の `qBlock` | 練習問題 `:::q` を読み、枠を描き、`site/assets/qbank.js`（`window.QBANK`、`window.QTOPICS`）にまとめる。ビルドの最後に、問題が重要度 × 3 に足りない主題を知らせる |
| `src/assets/qa.js` | 練習問題の答え合わせと記録、苦手の復習、模擬試験、進み具合の表 |

## 練習問題の記法

````
:::q 2.08.1-01 single        ← ID（細かい項目 - 通し番号）と形（single / multi / fill）
問題文（段落、```text のコードブロック）
- [ ] まちがいの選択肢
- [x] 正解の選択肢             ← multi は正解が複数
= 入力の正解                    ← fill。何行でも（どれか 1 つと一致すれば正解）
:::why
解説（正解の理由と、ほかの選択肢がなぜ違うか）
:::
:::
````

- 細かい項目ごとに重要度 × 5 問を目安にする（模擬試験 5 回ぶん）
- 序章の見本は 91〜99 番を使う

## 検査

スクラッチパッドの `linuc2/check.mjs chNN [-v]`（```sh run を小さな Linux で実行、練習問題の形と数）と `linuc2/qtest.mjs`（ヘッドレス Chrome で答え合わせ・復習・模試）。
