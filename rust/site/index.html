すべての章

序はじめにこの本が何を目指していて、どう読めばいいのか。Rust がなぜ「難しいけど価値がある」と言われるのかを、最初に地図として渡します。5 節図 31章事始めRust をインストールし、最初のプログラムを書いて動かします。rustc で直接コンパイルする方法と、実際の開発で使う cargo の両方を体験します。4 節図 52章数当てゲームを作る小さなゲームを一から作りながら、let、match、メソッド、外部クレートなどを駆け足で体験します。細かい理屈は後の章に回し、まずは手を動かしましょう。6 節図 63章一般的なプログラミングの概念変数、型、関数、コメント、制御フロー。どの言語にもある道具を、Rust ではどう書き、どこが他の言語と違うのかに絞って確認します。6 節図 74章所有権を理解するRust を Rust たらしめている仕組み、所有権。GC なしでメモリ安全を保証するためのルールを、スタックとヒープの絵を動かしながら理解します。4 節図 155章構造体で関係のあるデータをまとめる関連する値に名前を付けて 1 つにまとめる構造体。定義と生成、所有権との関係、そして impl でメソッドを生やすところまで進みます。4 節図 46章enum とパターンマッチング「いくつかの可能性のうちどれか 1 つ」を表す enum と、それを漏れなく場合分けする match。null がない Rust で「値がないかもしれない」を表す Option もここで登場します。4 節図 47章パッケージ・クレート・モジュールでプロジェクトを整理するコードが大きくなったら、分けて整理する必要があります。パッケージ、クレート、モジュール、パスという 4 つの道具の関係を、入れ子の図とモジュールの木で整理します。7 節図 98章一般的なコレクション実行中に伸び縮みする 3 つの定番コレクション、ベクタ・文字列・ハッシュマップ。どれも中身はヒープにあり、所有権と借用のルールがそのまま効いてきます。5 節図 79章エラー処理Rust はエラーを「回復できないもの」と「回復できるもの」にはっきり分けます。前者は panic!、後者は Result。そして ? 演算子で、エラー処理のコードを驚くほど短く書けます。6 節図 610章ジェネリクス・トレイト・ライフタイム重複を消すための 3 つの抽象化。型を抽象化するジェネリクス、振る舞いを抽象化するトレイト、参照の有効範囲をコンパイラに伝えるライフタイム。特にライフタイムは、図で範囲を見ながら理解します。6 節図 811章自動テストを書く型システムが保証できるのは「型が正しいこと」まで。「やりたいことを正しくやっているか」はテストで確かめます。テストの書き方、走らせ方、そしてユニットテストと結合テストの置き場所を整理します。4 節図 512章入出力プロジェクト：コマンドラインツールを作る簡易版の grep「minigrep」を作ります。引数の処理、ファイルの読み込み、エラー処理、モジュール分割、テスト駆動開発、環境変数、標準エラー出力。ここまでの章の総まとめです。8 節図 513章関数型言語の機能：クロージャとイテレータ関数を値として扱うクロージャと、要素の並びを順に処理するイテレータ。Rust らしい簡潔なコードの土台であり、しかも手書きのループと同じ速さで動きます。5 節図 814章Cargo と crates.io をもっと使うビルド設定の切り替え、ドキュメントの書き方、crates.io への公開、複数のクレートをまとめるワークスペース、そしてコマンドの追加。Cargo のもう一歩進んだ使い方です。6 節図 515章スマートポインタポインタのように振る舞いながら、追加の情報と機能を持つ構造体、スマートポインタ。ヒープに置く Box、所有者を複数にする Rc、実行時に借用を検査する RefCell。メモリがいつ確保され、いつ解放されるのかを図で追いかけます。8 節図 1516章恐れずに並行性を扱うスレッド、メッセージパッシング、共有状態。並行プログラミングの典型的なバグの多くを、Rust は所有権と型システムによってコンパイル時に捕まえます。「恐れることのない並行性（fearless concurrency）」の仕組みを見ていきます。6 節図 917章Rust のオブジェクト指向プログラミング機能Rust はオブジェクト指向言語なのか。カプセル化・継承・ポリモーフィズムという 3 つの特徴と Rust の対応を確かめ、トレイトオブジェクトの仕組みと、状態パターンの 2 通りの実装を比べます。4 節図 718章パターンとマッチングmatch や let で何度も使ってきた「パターン」を体系的に整理します。どこで使えるのか、失敗し得るのか、そしてどんな書き方ができるのか。リファレンスとして手元に置いておける章です。5 節図 519章高度な機能unsafe Rust、高度なトレイト、高度な型、関数ポインタ、そしてマクロ。普段は使わないけれど、ライブラリのソースを読むときや、特殊な問題に出会ったときに必要になる機能を集めました。7 節図 820章最後のプロジェクト：マルチスレッドの Web サーバを作るTCP と HTTP の基本から始めて、シングルスレッドのサーバを作り、スレッドプールでマルチスレッド化し、最後に正しくシャットダウンさせます。所有権、トレイト、クロージャ、スマートポインタ、並行性。すべてがここで合流します。6 節図 8付録付録キーワード、演算子と記号、derive できるトレイト、便利な開発ツール、エディション、そして Rust がどう作られているか。本文を読みながら、あるいは読み終えた後に引くための資料です。7 節図 4
