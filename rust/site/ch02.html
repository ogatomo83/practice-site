第 2 章

数当てゲームを作る

小さなゲームを一から作りながら、let、match、メソッド、外部クレートなどを駆け足で体験します。細かい理屈は後の章に回し、まずは手を動かしましょう。

6 節図 6 点目安 60 分

2.1作るものと全体の流れ

作るのは古典的な数当てゲームです。

  1. プログラムが 1 から 100 までの数をランダムに 1 つ選ぶ
  2. プレイヤーが予想を入力する
  3. 予想が大きすぎるか、小さすぎるかを教える
  4. 当たったらお祝いのメッセージを出して終わる。外れたら 2 に戻る

まずはプロジェクトを作ります。

ターミナル
$ cargo new guessing_game$ cd guessing_game

2.2予想を入力してもらう

最初のステップは、プレイヤーに予想を入力してもらい、それをそのまま表示するところまでです。

src/main.rs
use std::io; fn main() {    println!("Guess the number!");     println!("Please input your guess.");     let mut guess = String::new();     io::stdin()        .read_line(&mut guess)        .expect("Failed to read line");     println!("You guessed: {guess}");}

1 行ずつ読んでいきましょう。

use でライブラリを持ち込む

Rust
use std::io;

入力を受け取るには、標準ライブラリ std の中の io（入出力）モジュールを使います。Rust は、すべてのプログラムに自動で持ち込まれる最小限のセット（prelude と呼ばれます）を用意していますが、それ以外は use で明示的に持ち込みます。

変数に値を入れる

Rust
let mut guess = String::new();

let は変数を作る文です。Rust の変数はデフォルトで不変なので、後で中身を変えたいなら mut を付けます。

Rust
let apples = 5;      // 不変let mut bananas = 5; // 可変

String::new() は、空の String を作る関数です。:: は「String 型に結びついた new という関数」を意味します。このような型に結びついた関数を関連関数と呼びます。

入力を読む

Rust
io::stdin()    .read_line(&mut guess)    .expect("Failed to read line");

io::stdin() は標準入力を扱うハンドルを返します。その read_line メソッドが、ユーザーが Enter を押すまでの 1 行を読んで、guess の後ろに追加します。

&mut guess の & は参照です。guess そのものを渡すのではなく、「guess の場所」を教えて書き込んでもらいます。参照はデフォルトで不変なので、書き込みを許すには &mut と書きます。参照は第 4 章の主役なので、今は「書き込んでもらうために場所を貸している」と理解しておけば十分です。

Result で失敗に備える

read_line は、読み込みが成功したかどうかを Result という型で返します。Result は「成功（Ok）か失敗（Err）のどちらか」を表す型です。

expect を呼ばずにおくと、コンパイラが警告を出します。

ターミナル
warning: unused `Result` that must be used  --> src/main.rs:10:5   |10 |     io::stdin().read_line(&mut guess);   |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^   |   = note: this `Result` may be an `Err` variant, which should be handled

「失敗するかもしれない処理の結果を無視していますよ」という警告です。Rust は、エラーを黙って握りつぶすことを許しません。ちゃんとしたエラー処理は第 9 章で学びます。

値を埋め込んで表示する

Rust
println!("You guessed: {guess}");

{} は値を埋め込むプレースホルダです。中に変数名を書くとその値が入ります。式の値を埋め込みたいときは、空の {} を置いて後ろに式を並べます。

Rust
let x = 5;let y = 10; println!("x = {x} and y + 2 = {}", y + 2); // x = 5 and y + 2 = 12

動かしてみる

ターミナル
$ cargo run   Compiling guessing_game v0.1.0 (file:///projects/guessing_game)    Finished `dev` profile [unoptimized + debuginfo] target(s) in 6.44s     Running `target/debug/guessing_game`Guess the number!Please input your guess.6You guessed: 6

2.3秘密の数を作る：外部クレートを使う

次に、ランダムな数を生成します。Rust の標準ライブラリには乱数の機能がありません。代わりに、コミュニティが作った rand クレートを使います。

クレートは Rust のコードのまとまりの単位です。今作っている guessing_game は実行ファイルになるバイナリクレート、rand は他のプログラムから使われるライブラリクレートです。

依存関係を追加する

Cargo.toml の [dependencies] に rand を書きます。

Cargo.toml
[dependencies]rand = "0.8.5"

"0.8.5" は、正確には ^0.8.5 の省略形で、「0.8.5 以上で、0.9.0 未満」という意味です。この範囲なら公開 API の互換性が保たれる、というセマンティックバージョニング（SemVer）の約束に基づいています。

この状態でビルドすると、Cargo が rand と、rand が依存しているクレートを自動でダウンロードしてビルドします。

ターミナル
$ cargo build    Updating crates.io index  Downloaded rand v0.8.5  Downloaded libc v0.2.127  Downloaded getrandom v0.2.7  Downloaded cfg-if v1.0.0  Downloaded ppv-lite86 v0.2.16  Downloaded rand_chacha v0.3.1  Downloaded rand_core v0.6.3   Compiling rand_core v0.6.3   Compiling libc v0.2.127   Compiling getrandom v0.2.7   Compiling rand_chacha v0.3.1   Compiling rand v0.8.5   Compiling guessing_game v0.1.0 (file:///projects/guessing_game)    Finished `dev` profile [unoptimized + debuginfo] target(s) in 2.53s

Cargo.toml に書いたのは rand だけなのに、たくさんのクレートがダウンロードされています。これは rand 自身も他のクレートに依存しているからです。

クレートは crates.io という公開レジストリからダウンロードされます。誰でも自分のクレートを公開できます（第 14 章）。

Cargo.lock で同じビルドを再現する

最初のビルドのとき、Cargo は条件に合うバージョンを決めて、Cargo.lock というファイルに記録します。2 回目以降のビルドでは、Cargo.toml ではなく Cargo.lock に書かれたバージョンが使われます。

その後 rand の 0.8.6 が公開されても、Cargo.lock がある限り 0.8.5 が使われ続けます。新しい版に上げたいときは、cargo update を実行します。これは Cargo.toml の範囲内（0.9 未満）で最新の版を探し、Cargo.lock を書き換えます。0.9 系に上げたいなら、Cargo.toml の数字を自分で書き換えます。

Cargo.lock は Git にコミットしておきましょう。チームの誰がいつビルドしても同じ依存関係になります。

乱数を生成する

src/main.rs
use std::io;use rand::Rng; fn main() {    println!("Guess the number!");     let secret_number = rand::thread_rng().gen_range(1..=100);     println!("The secret number is: {secret_number}");     println!("Please input your guess.");     let mut guess = String::new();     io::stdin()        .read_line(&mut guess)        .expect("Failed to read line");     println!("You guessed: {guess}");}
  • use rand::Rng; は Rng というトレイトを持ち込みます。トレイトはメソッドの集まりで、gen_range は Rng トレイトのメソッドです。トレイトをスコープに入れないとそのメソッドは呼べません（第 10 章）。
  • rand::thread_rng() は、今のスレッド専用の乱数生成器を返します。
  • gen_range(1..=100) は範囲の中から 1 つ選びます。1..=100 は「1 以上 100 以下」です。1..100 だと 100 を含みません。
コツクレートの使い方を調べる

cargo doc --open を実行すると、自分のプロジェクトが依存しているすべてのクレートのドキュメントをビルドして、ブラウザで開いてくれます。rand の他の機能を知りたくなったら試してください。

秘密の数を表示しているのは開発中の確認用です。完成前に消します。

2.4予想と秘密の数を比べる

src/main.rsコンパイルエラーになる
use rand::Rng;use std::cmp::Ordering;use std::io; fn main() {    // --snip--     println!("You guessed: {guess}");     match guess.cmp(&secret_number) {        Ordering::Less => println!("Too small!"),        Ordering::Greater => println!("Too big!"),        Ordering::Equal => println!("You win!"),    }}

cmp メソッドは 2 つの値を比べて、Ordering という enum（列挙型）を返します。Ordering には Less（小さい）、Greater（大きい）、Equal（等しい）の 3 つの値（列挙子）があります。

match 式は、値をいくつかのパターンと上から順に照らし合わせて、最初に合ったパターンのアーム（腕）のコードを実行します。

ただ、このコードはコンパイルできません。

ターミナル
error[E0308]: mismatched types  --> src/main.rs:22:21   |22 |     match guess.cmp(&secret_number) {   |                 --- ^^^^^^^^^^^^^^ expected `&String`, found `&{integer}`   |                 |   |                 arguments to this method are incorrect   |   = note: expected reference `&String`              found reference `&{integer}`
error[E0308]型が一致しません

guess は String（文字列）、secret_number は数値です。Rust は強い静的型付けの言語なので、文字列と数値を比べることはできません。JavaScript のように暗黙に変換してくれることもありません。比べる前に、どちらかの型をそろえる必要があります。

secret_number の型は書いていませんが、Rust は 1..=100 から整数だと推論しています。特に指定がなければ整数は i32 になります。

文字列を数値に変換する

src/main.rs
    // --snip--     let mut guess = String::new();     io::stdin()        .read_line(&mut guess)        .expect("Failed to read line");     let guess: u32 = guess.trim().parse().expect("Please type a number!");     println!("You guessed: {guess}");     match guess.cmp(&secret_number) {        Ordering::Less => println!("Too small!"),        Ordering::Greater => println!("Too big!"),        Ordering::Equal => println!("You win!"),    }

すでに guess という変数があるのに、また let guess と書いています。これはシャドーイング（覆い隠し）という機能で、同じ名前の新しい変数を作って前の変数を隠します。「文字列の guess」から「数値の guess」に変換するような場面で、guess_str と guess_num のように名前を分けずに済みます（第 3 章）。

右辺を分解すると次のとおりです。

  • ユーザーが 5 と打って Enter を押すと、guess には "5\n" が入っています（Windows では "5\r\n"）。trim は前後の空白と改行を取り除きます。
  • parse は文字列を数値に変換します。どの型に変換するかは、左辺の let guess: u32 の型注釈から推論されます。u32 は 32 ビットの符号なし整数です。
  • 比較相手の secret_number も、この比較から u32 だと推論し直されます。
  • parse は "A👍%" のような数値にならない文字列では失敗するので、Result を返します。ここでは expect で、失敗したらプログラムを止めます。

2.5ループで何度も予想させる

loop キーワードは無限ループを作ります。

src/main.rs
    // --snip--     println!("The secret number is: {secret_number}");     loop {        println!("Please input your guess.");         // --snip--         match guess.cmp(&secret_number) {            Ordering::Less => println!("Too small!"),            Ordering::Greater => println!("Too big!"),            Ordering::Equal => {                println!("You win!");                break;            }        }    }}

正解したときのアームを { } で囲んで複数の文を書けるようにし、break でループを抜けます。loop を抜けると main の終わりに達するので、プログラムも終了します。

数字以外の入力を無視する

今のままだと、数字以外を入力するとプログラムが止まってしまいます。

ターミナル
Please input your guess.foothread 'main' panicked at src/main.rs:28:47:Please type a number!: ParseIntError { kind: InvalidDigit }

expect でプログラムを止める代わりに、match でエラーを処理しましょう。

Rust
let guess: u32 = match guess.trim().parse() {    Ok(num) => num,    Err(_) => continue,};

parse が返す Result も、Ordering と同じく enum です。match で Ok と Err の場合に分けます。

  • Ok(num) — 成功したら、中の数値に num という名前を付けて、それを式の値にする。それが guess に入る
  • Err(_) — 失敗したら、continue でループの先頭に戻ってもう一度入力を求める。_ は「中身は何でもいい、使わない」という意味のワイルドカード

2.6完成したコード

開発用の秘密の数の表示を消して、完成です。

src/main.rs
use rand::Rng;use std::cmp::Ordering;use std::io; fn main() {    println!("Guess the number!");     let secret_number = rand::thread_rng().gen_range(1..=100);     loop {        println!("Please input your guess.");         let mut guess = String::new();         io::stdin()            .read_line(&mut guess)            .expect("Failed to read line");         let guess: u32 = match guess.trim().parse() {            Ok(num) => num,            Err(_) => continue,        };         println!("You guessed: {guess}");         match guess.cmp(&secret_number) {            Ordering::Less => println!("Too small!"),            Ordering::Greater => println!("Too big!"),            Ordering::Equal => {                println!("You win!");                break;            }        }    }}
