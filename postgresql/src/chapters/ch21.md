## psql のコマンド {#psql}

`psql` は、PostgreSQL の公式のコマンドラインのクライアントです。バックスラッシュで始まる**メタコマンド**は psql 自身の機能で、SQL ではありません（この本のブラウザの環境では使えません）。

```console norun
$ psql -h localhost -U postgres -d shop
```

| コマンド | 意味 |
| --- | --- |
| `\l` | データベースの一覧 |
| `\c shop` | データベース shop に接続し直す |
| `\dt` | テーブルの一覧 |
| `\d orders` | orders の列・インデックス・制約 |
| `\d+ orders` | さらに詳しく（サイズ、ストレージなど） |
| `\di` / `\dv` / `\df` | インデックス / ビュー / 関数の一覧 |
| `\dn` / `\du` | スキーマ / ロールの一覧 |
| `\x` | 縦長表示の切り替え（列が多いとき） |
| `\timing` | 実行時間の表示の切り替え |
| `\e` | エディタで直前の SQL を編集 |
| `\i file.sql` | ファイルの SQL を実行 |
| `\copy t from 'f.csv' csv header` | 手元のファイルを読み込む |
| `\watch 2` | 直前の SQL を 2 秒ごとに繰り返す |
| `\set ON_ERROR_STOP on` | エラーで止める（スクリプト用） |
| `\gset` | 結果を psql の変数に入れる |
| `\q` | 終了 |
| `\?` / `\h select` | メタコマンドのヘルプ / SQL の構文のヘルプ |

```psql norun
shop=# \d order_items
             Table "public.order_items"
   Column   |  Type   | Collation | Nullable | Default
------------+---------+-----------+----------+---------
 order_id   | integer |           | not null |
 product_id | integer |           | not null |
 quantity   | integer |           | not null |
 unit_price | integer |           | not null |
Indexes:
    "order_items_pkey" PRIMARY KEY, btree (order_id, product_id)
Check constraints:
    "order_items_quantity_check" CHECK (quantity > 0)
Foreign-key constraints:
    "order_items_order_id_fkey" FOREIGN KEY (order_id) REFERENCES orders(id)
    "order_items_product_id_fkey" FOREIGN KEY (product_id) REFERENCES products(id)
```

psql のプロンプトの記号には意味があります。

| プロンプト | 意味 |
| --- | --- |
| `shop=#` | スーパーユーザで接続中 |
| `shop=>` | 一般ユーザで接続中 |
| `shop-#` | SQL の続きを入力中（`;` がまだない） |
| `shop*#` | トランザクションの中 |
| `shop!#` | 失敗したトランザクションの中（`rollback` が必要） |

## よく出る SQLSTATE {#sqlstate}

SQLSTATE は 5 文字のエラーコードです。先頭 2 文字が分類を表します。アプリケーションでは、メッセージの文字列ではなく、このコードでエラーを判定します。

| コード | 名前 | 意味 | 対処 | 章 |
| --- | --- | --- | --- | --- |
| `23502` | not_null_violation | NOT NULL 違反 | 値を入れる | 5 |
| `23503` | foreign_key_violation | 外部キー違反 | 参照先を確かめる | 2, 5 |
| `23505` | unique_violation | 一意性違反 | 重複を避ける / UPSERT | 5, 6 |
| `23514` | check_violation | CHECK 違反 | 値を直す | 5 |
| `23P01` | exclusion_violation | 排他制約違反 | 重なりを避ける | 5 |
| `22003` | numeric_value_out_of_range | 数値が範囲外 | 型を大きくする | 4 |
| `22012` | division_by_zero | 0 で割った | `nullif(x, 0)` | |
| `22P02` | invalid_text_representation | 入力の形式が不正 | 入力を確かめる | 4 |
| `42601` | syntax_error | 文法の誤り | SQL を直す | 15 |
| `42P01` | undefined_table | 表がない | 名前・スキーマ・search_path | 0 |
| `42703` | undefined_column | 列がない | 名前・クォート・評価順 | 3 |
| `42702` | ambiguous_column | 列名が曖昧 | 表の別名を付ける | 7 |
| `42803` | grouping_error | GROUP BY にない列 | 集約するか GROUP BY に加える | 8 |
| `42501` | insufficient_privilege | 権限がない | GRANT | 20 |
| `21000` | cardinality_violation | サブクエリが複数行 | `in` を使う / `limit 1` | 9 |
| `25P02` | in_failed_sql_transaction | 失敗したトランザクションの中 | ROLLBACK | 6 |
| `40001` | serialization_failure | 直列化の失敗 | **再試行** | 13 |
| `40P01` | deadlock_detected | デッドロック | **再試行**、ロックの順番を揃える | 17 |
| `55P03` | lock_not_available | ロックが取れない（nowait / lock_timeout） | 時間をおいて再試行 | 17 |
| `57014` | query_canceled | 取り消された（statement_timeout など） | 問い合わせを速くする | |
| `53300` | too_many_connections | 接続数の上限 | 接続プーリング | 20 |

ブラウザの環境でも、エラーの右端に SQLSTATE が表示されます。わざとエラーを起こして、コードを確かめてみてください。

```sql run error
select 1 / 0;
```

## システムカタログ {#catalog}

PostgreSQL は、自分自身の情報（テーブル、列、インデックス、統計）も表として持っています。これを**システムカタログ**と呼びます。

| カタログ / ビュー | 中身 | 使った章 |
| --- | --- | --- |
| `pg_class` | テーブル・インデックス・ビューなど（relpages, reltuples） | 12, 15 |
| `pg_attribute` | 列 | 実験場 |
| `pg_index` | インデックスの定義 | |
| `pg_namespace` | スキーマ | |
| `pg_roles` | ロール | 20 |
| `pg_settings` | 設定値 | 16, 20 |
| `pg_stats` | 列の統計情報（読みやすいビュー） | 15 |
| `pg_locks` | 取得中のロック | 17 |
| `pg_stat_activity` | 接続と実行中の文 | 15, 17 |
| `pg_stat_user_tables` / `_indexes` | 表・インデックスの利用統計 | 13, 14 |
| `information_schema.*` | SQL 標準の形式のカタログ | 5, 11 |

```sql run
-- 文具店の表を、サイズの大きい順に
select c.relname as 表, c.relkind as 種類, c.reltuples::bigint as 行数の見積もり,
       pg_size_pretty(pg_total_relation_size(c.oid)) as インデックス込みのサイズ
from pg_class c join pg_namespace n on n.oid = c.relnamespace
where n.nspname = 'public' and c.relkind = 'r'
order by pg_total_relation_size(c.oid) desc;
```

## 用語集 {#glossary}

| 用語 | 意味 | 章 |
| --- | --- | --- |
| ACID | 原子性・一貫性・独立性・永続性。トランザクションが守る 4 つの性質 | 13 |
| autovacuum | 自動で VACUUM と ANALYZE を行うバックグラウンドの仕組み | 13 |
| B-tree | 値を並べて保持する、背の低い木の形のインデックス | 14 |
| BRIN | ブロックの範囲ごとの最小値・最大値だけを持つ小さなインデックス | 14 |
| CTE | WITH 句で名前を付けたサブクエリ | 9 |
| ctid | 行の物理的な住所（ページ番号, 行ポインタ番号） | 12 |
| FPI | 全ページ画像。チェックポイント後の最初の変更で WAL に書かれる | 16 |
| FSM | 空き領域マップ。ページごとの空き容量 | 12 |
| GIN | 要素ごとの転置インデックス。配列・jsonb・全文検索に使う | 14, 19 |
| GiST | 範囲や図形のための、汎用の木のインデックス | 5, 14 |
| HOT | インデックスを更新せずに済む UPDATE（Heap-Only Tuple） | 12 |
| LSN | WAL の中の位置 | 16 |
| MVCC | 多版型同時実行制御。行の複数の版を持ち、読みと書きが互いを待たない | 13 |
| NULL | 値がないことを表す印。比較の結果は UNKNOWN になる | 2 |
| PITR | 任意の時点への復旧。ベースバックアップと WAL アーカイブで行う | 16, 20 |
| RLS | 行レベルセキュリティ。行ごとに見える範囲を制御する | 20 |
| SSI | 直列化可能スナップショット分離。SERIALIZABLE の実装 | 13 |
| TOAST | 大きな値を圧縮し、別のテーブルに追い出す仕組み | 12 |
| VACUUM | 死んだタプルを回収し、凍結を行う処理 | 13 |
| VM | 可視性マップ。ページの行が全員から見えるか、凍結済みか | 12 |
| WAL | 先行書き込みログ。データより先に変更の記録を書く | 16 |
| XID | トランザクション ID。32 ビットで周回する | 13 |
| xmin / xmax | タプルを作った / 消した（ロックした）トランザクションの ID | 12, 13, 17 |
| 共有バッファ | ページを読み込んでおく、全プロセス共有のメモリ | 12 |
| 結合 | 2 つの表の行を、条件に合うものどうし組み合わせること | 7 |
| 候補キー | 行を一意に決める最小の列の組 | 2 |
| 実行計画 | プランナが選んだ、問い合わせの実行方法の木 | 15 |
| 正規化 | 同じ事実を 1 か所にだけ持つよう、表を分けること | 11 |
| スナップショット | ある時点で、どのトランザクションが終わっていたかの記録 | 13 |
| タプル | 行。とくにディスク上の行の版 | 2, 12 |
| チェックポイント | 汚れたページを書き出し、再生の起点を進めること | 16 |
| デッドロック | トランザクションが互いのロックを待ち合って進めない状態 | 17 |
| パーティショニング | 1 つの表を範囲などで複数の物理的な表に分けること | 20 |
| ページ（ブロック） | 8 KB の、読み書きの単位 | 12 |
| プランナ | 実行方法の候補のコストを見積もり、一番安いものを選ぶ部分 | 15 |
| 分離レベル | 同時に動くトランザクションどうしがどこまで影響し合うかの段階 | 13 |
| 凍結 | 古い行の XID を「どの XID より過去」として扱わせる処理 | 13 |
