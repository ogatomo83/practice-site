序はじめにこの本が何を目指し、どう読むと効くのか。ブラウザの中で PostgreSQL を動かす仕組みと、全章で使うサンプルの文具店データベースを最初に紹介します。5 節図 2SQL 31章データベースと SQL の歴史1960 年代の階層型データベースから、Codd のリレーショナルモデル、SQL の誕生、Berkeley の POSTGRES、そして PostgreSQL 18 まで。今の設計がなぜそうなっているのかを、歴史からつかみます。9 節図 5SQL 32章リレーショナルモデル表、行、列、キーという言葉の正確な意味と、表どうしを組み合わせる「関係代数」の 5 つの操作。そして SQL で一番つまずきやすい NULL と三値論理を、実行しながら確かめます。6 節図 3SQL 223章SELECT の基本データを読み出す SELECT 文を、列の選び方、行の絞り込み、並べ替え、件数の制限の順に学びます。SQL が「書いた順」ではなく「決まった順」で評価されることを図で押さえます。10 節図 1SQL 274章データ型数値、文字列、日付と時刻、真偽値、配列、JSON、範囲型。PostgreSQL の豊富な型のうち、実務でよく使うものを、それぞれのサイズと落とし穴と一緒に学びます。10 節図 1SQL 255章テーブル定義と制約CREATE TABLE でテーブルを作り、NOT NULL・主キー・一意・CHECK・外部キー・排他制約で「入ってはいけないデータ」を締め出します。ALTER TABLE での変更と、スキーマによる名前空間も扱います。9 節図 2SQL 276章データの変更INSERT・UPDATE・DELETE でデータを書き換え、RETURNING で結果を受け取り、ON CONFLICT と MERGE で「あれば更新、なければ追加」を 1 文で書きます。変更を取り消せるトランザクションの入り口にも触れます。9 節図 1SQL 237章結合 JOIN分かれて保存されたテーブルを、値の一致でつなぎ直すのが JOIN です。直積から始めて、内部結合・外部結合・自己結合・LATERAL まで、行がどう組み合わされるかを図で追いかけます。9 節図 6SQL 218章集約とグループ化合計・平均・件数を求める集約関数と、行をグループに分ける GROUP BY、グループを絞る HAVING。FILTER 句、ROLLUP による小計、結合したあとの集計で数字が膨らむ罠まで扱います。9 節図 3SQL 209章サブクエリと CTESELECT の中に SELECT を書くサブクエリと、名前を付けて段階的に組み立てる CTE（WITH 句）。再帰 CTE で木構造をたどり、データを書き換える CTE で複数の変更を 1 文にまとめます。8 節図 2SQL 1710章ウィンドウ関数行をまとめずに、ほかの行を見ながら計算するのがウィンドウ関数です。順位、累計、前の行との差、移動平均、グループごとの上位 N 件を、OVER 句ひとつで書けるようになります。8 節図 2SQL 1611章スキーマ設計と正規化同じ事実を 1 か所にだけ書くための考え方が正規化です。悪い設計で起きる 3 つの異常を実際に起こし、第 1〜第 3 正規形で直します。多対多の関係、あえて崩す非正規化、よくあるアンチパターンも扱います。10 節図 3SQL 812章ストレージ：ページとタプルテーブルの行は、ディスクの上で 8 KB の「ページ（ブロック）」に詰められています。ファイルの置き場所から、ページの内部構造、タプルのヘッダ、TOAST、空き領域マップ、共有バッファまで、pageinspect で実物を覗きながら学びます。10 節図 6SQL 2113章トランザクションと MVCC読む人と書く人が互いを待たずに済む、PostgreSQL の多版型同時実行制御（MVCC）。xmin・xmax とスナップショットで「どの版が見えるか」が決まる仕組み、4 つの分離レベル、VACUUM とトランザクション ID の周回までを追いかけます。9 節図 5SQL 1614章インデックス全ページを読む代わりに、目的の行の住所（ctid）を素早く引くための索引。B-tree の木の形を pageinspect で覗き、複合・式・部分・カバリングインデックス、GIN・GiST・BRIN の使い分け、インデックスの代償までを学びます。8 節図 3SQL 2015章実行計画と EXPLAINSQL が文字列から結果になるまでの 5 つの段階と、その中心にいるプランナ。EXPLAIN の読み方、コストを手で計算して一致させる練習、統計情報と見積もりの誤り、結合の順番と方法の選び方を学びます。9 節図 1SQL 2316章WAL・リカバリ・レプリケーションコミットした変更が電源断でも消えないのは、データより先にログを書く「先行書き込みログ（WAL）」のおかげです。pg_walinspect で自分の INSERT や UPDATE のログを読み、チェックポイント、全ページ書き込み、クラッシュリカバリ、レプリケーションへとつなげます。10 節図 4SQL 1117章ロックと同時実行MVCC で読み書きは互いを待たなくなりましたが、書く人どうし、そしてテーブルの定義を変える操作は、やはり順番を守る必要があります。テーブルロックの 8 つのモード、タプルに刻まれる行ロック、デッドロック、SKIP LOCKED、勧告的ロックを学びます。8 節図 4SQL 1018章ビュー・関数・トリガ問い合わせに名前を付けるビューとマテリアライズドビュー、SQL と PL/pgSQL で書く関数とプロシージャ、データの変更に反応して動くトリガ。データベースの中にロジックを置くための道具と、その使いどころを学びます。7 節図 1SQL 1819章JSON・全文検索・拡張機能jsonb の演算子と関数、JSON パスと JSON_TABLE、GIN インデックス。英語の全文検索と、日本語の部分一致を速くする pg_trgm。そして PostgreSQL を「何にでもなれるデータベース」にしている拡張機能の仕組みを学びます。7 節図 1SQL 2520章運用：権限・バックアップ・チューニング本番で PostgreSQL を動かし続けるための知識。ロールと権限、行レベルセキュリティ、バックアップの 3 つの方式、メモリとチェックポイントの設定、接続プーリング、パーティショニング、監視とバージョンアップを、ここまでの章の内容と結び付けて整理します。10
