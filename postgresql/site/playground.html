SQL を自由に試す

ブラウザの中で PostgreSQL 18 が動いています。テーブルを作っても壊しても、上の「リセット」で最初の状態に戻せます。内容はページを閉じると消えます。

playground.sql⌘↵
-- 好きな SQL を書いて「実行」（Ctrl / ⌘ + Enter）
-- 複数の文はセミコロンで区切ると順に実行されます
select c.name as 顧客, count(distinct o.id) as 注文数, sum(oi.quantity * oi.unit_price) as 購入額
from customers c
left join orders o on o.customer_id = c.id and o.status <> 'cancelled'
left join order_items oi on oi.order_id = o.id
group by c.id, c.name
order by 購入額 desc nulls last;
