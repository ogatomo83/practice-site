はじめに

はじめに：合格メソッド

LinuC レベル1 の試験の形、出題範囲と重要度、図解 Linux のどこが役に立ち、どこを新しく学ぶか。診断 → 学ぶ → 解く → 模試の 4 段階の進め方と、6 週間の計画、練習問題の使い方をまとめます。

7 節図 3 点練習問題 3 問目安 20 分

0.1この本について

この本は、LinuC（リナック）レベル1 に合格するための学習書です。図解 Linux を読み終えた人を前提にしています。

「読み終えた」といっても、全部を覚えている必要はありません。図解 Linux で身に付けたのは、プロセス、ファイルディスクリプタ、inode、パーミッション、シェルの仕組みです。この本では、その知識を試験の形で引き出せるようにします。足りないところは、ここで補います。

図解 Linux とこの本の違いは、目的です。

図解 Linux図解 LinuC
目的仕組みを分かる試験で正しく選べる
範囲カーネルの中まで深く出題範囲を広く、漏れなく
中心図と、小さな Linux で動かすこと本番の形の練習問題と、苦手の復習
覚えること少なく。仕組みから導くオプション、ファイルの場所、ポート番号も覚える

試験には、どうしても覚えるしかないものがあります。useradd の -m の意味、/etc/cron.allow の役目、22/SSH と 123/NTP などです。この本は、覚えることを表にまとめ、練習問題で何度も引き出すことで定着させます。

メモ問題はこのサイトのオリジナルです

練習問題と模擬試験は、出題範囲をもとにこのサイトが作ったものです。本番の問題を写したものではありません。形（選択肢の数、「2 つ選択してください」、コマンドを入力する問題）は、本番に近づけてあります。

0.2試験の形

LinuC レベル1 に認定されるには、101 試験と 102 試験の両方に合格します。どちらから受けてもかまいません。

項目内容
問題の数1 回約 60 問
時間90 分（そのうち約 5 分は、試験の後のアンケート）
形コンピュータで受ける（CBT）。ほとんどはマウスで選ぶ問題で、キーボードで入力する問題が少しある
受験料1 回 16,500 円（税込）
認定の条件101 と 102 の両方に、5 年以内に合格する
合格点公表されていない

60 問を約 85 分で解くので、1 問にかけられるのは 1 分 20 秒ほどです。迷った問題に印を付けて先へ進み、最後に戻る、という時間の使い方が大事です。

合格点は公表されていません。この本の模擬試験では、80% 以上を 3 回続けて取ることを目標にします。本番の問題は、模試より見慣れない聞き方をしてくるからです。

注意申し込む前に、公式のページを確かめる

受験料、試験の形、出題範囲は変わることがあります。上の表は、この本を書いたときに LinuC の公式サイト で確かめたものです。申し込む前に、もう一度公式のページを見てください。

0.3出題範囲と重要度

出題範囲は、11 の主題（1.01〜1.11）に分かれています。1〜5 が 101 試験、6〜11 が 102 試験です。各主題の下に細かい項目があり、それぞれに重要度が付いています。重要度は、各試験で合計 60 です。問題の数が約 60 なので、重要度は、だいたい出る問題の数だと考えてかまいません。

101 では「インストール・仮想化・起動・プロセス」と「コマンド」で半分を占めます。102 では「ネットワーク」がいちばん大きく、「システム管理」と「セキュリティ」が続きます。細かい項目でいちばん重いのは、102 の 1.06.2 シェルスクリプト（重要度 6） です。

0.4図解 Linux で学んだこと、ここで学ぶこと

図解 Linux とこの本の範囲を比べると、3 つに分かれます。

  • 図解 Linux でほぼ足りる：復習と、試験の形の練習だけでよい
  • 一部を学んだ：仕組みは分かっているので、コマンドとオプションを足す
  • 図解 Linux になかった：この本で一から学ぶ
主題図解 Linuxこの本で足すこと
1.01 インストール・仮想化・起動・プロセス一部（7 章 プロセス、8 章 シグナル、17 章 起動と init、19 章 コンテナ）インストールの手順、SSH の接続、ハイパーバイザー、virsh と docker、screen と tmux、X Window System
1.02 ファイル・ディレクトリほぼ足りる（3 章、4 章、11 章）tar と圧縮（gzip / bzip2 / xz）、locate、whereis、FHS
1.03 GNU と Unix のコマンド一部（2 章、5 章、9 章）expand・fmt・join・nl・od・paste・pr・split、正規表現、vi
1.04 パッケージ管理なかったapt、dpkg、yum（dnf）、rpm、リポジトリ
1.05 ディスク・ファイルシステム一部（11 章、12 章）カーネルモジュール、udev、パーティション（fdisk・gdisk・parted、MBR と GPT）、LVM、mkfs、スワップ、/etc/fstab
1.06 シェルとスクリプトほぼ足りる（6 章）設定ファイルの読まれる順番（/etc/profile、~/.bashrc …）
1.07 ネットワーク一部（16 章）サブネットと CIDR の計算、ポート番号、IPv6、ip・nmcli、dig・host、traceroute、resolv.conf と nsswitch.conf
1.08 システム管理一部（4 章）useradd などのアカウント管理、/etc/shadow、cron と at、ロケール
1.09 システムサービス一部（17 章 journalctl）時刻（chrony、timedatectl）、rsyslog、logrotate、MTA
1.10 セキュリティ一部（4 章 su と sudo）chage、lsof・fuser・nmap、/etc/sudoers、firewalld・iptables、SSH の鍵、gpg、クラウドのセキュリティ
1.11 オープンソースの文化なかったライセンス（GPL・LGPL・MIT・Apache…）、コミュニティ

大きく足りないのは、パッケージ管理、パーティションと LVM、vi、アカウント管理、cron、ログ、ネットワークの設定です。ここは重要度も高いので、時間をかけます。

0.5合格メソッド：診断 → 学ぶ → 解く → 模試

  1. 診断：最初に模擬試験を 1 回受けます。点数は気にしません。採点の後に出る「主題ごとの正答率」を見て、低い主題を 2〜3 個選びます
  2. 学ぶ：選んだ主題の章を読みます。図解 Linux で学んだ所は、章の中のリンクから戻って復習します。コマンドは、ページの中の小さな Linux で実際に打ちます
  3. 解く：章の最後の練習問題を解きます。まちがえた問題は記録され、苦手を解くのページに集まります。正解するまで繰り返します
  4. 模試：もう一度模擬試験を受けます。70% に届かない主題が残っていたら、2 に戻ります。80% 以上を 3 回続けて取れたら、本番を予約します
コツ選択肢の「ほかが違う理由」まで言えるようにする

練習問題の解説には、正解の理由だけでなく、ほかの選択肢がなぜ違うかを書いてあります。本番は、同じことを違う聞き方で問います。「この選択肢のオプションは、本当は何をするか」まで言えるようになると、聞き方が変わっても解けます。

0.66 週間の計画

1 日 1 時間ほどで、101 と 102 を続けて受ける計画の例です。

週やること目安
1 週目序章、101 の模試で診断。1.03（コマンド）と 1.02（ファイル）の章図解 Linux の復習が中心
2 週目1.04（パッケージ）と 1.05（ディスク）の章新しく覚えることが多い
3 週目1.01（インストール・仮想化・起動・プロセス）の章、苦手の復習、101 の模試80% を目指す。届いたら 101 を予約
4 週目102 の模試で診断。1.06（シェル）と 1.07（ネットワーク）の章サブネットの計算は手で何度も
5 週目1.08（システム管理）、1.09（サービス）の章設定ファイルの場所を表で覚える
6 週目1.10（セキュリティ）、1.11（オープンソース）の章、苦手の復習、102 の模試80% を 3 回で 102 を予約

101 と 102 の間を空けるなら、101 に合格してから 102 の計画を始めてもかまいません。2 つの合格は、5 年以内であれば認定されます。

0.7練習問題の使い方

練習問題は 3 つの形です。

  • 1 つ選ぶ：ラジオボタン
  • 複数選ぶ：チェックボックス。本番と同じく「2 つ選択してください」のように、選ぶ数を問題文に書きます
  • 入力する：コマンドやファイルの名前をキーボードで入力します。本番と同じく、綴りが完全に合っていないと不正解です。オプションの付け方が違う別解を認める問題もあります

試しに解いてみてください。

1.03.1-91

シェルの組み込みコマンドで、現在のシェルの中でスクリプトを実行し、スクリプトの中で設定した変数をそのまま残すものはどれか。

1.07.1-91複数選択

暗号化された通信に使われるポート番号を 2 つ選択してください。

1.02.1-91入力

ファイル report.txt の持ち主だけが読み書きでき、ほかのだれも何もできないようにする。chmod に与える 8 進数の権限を、3 桁の数字で入力してください。

答えると、正解と解説が出ます。解いた結果はこのブラウザに記録され、ページを開き直すと「前回：正解」「前回：不正解」の印が付きます。

要点まとめ
  • LinuC レベル1 は 101 と 102 の 2 つの試験。1 回約 60 問・90 分。合格点は公表されていないので、模試で 80% を目指す
  • 重要度の合計は各試験 60。重要度はだいたい出る問題の数
  • 図解 Linux で足りない大きな範囲は、パッケージ管理、パーティションと LVM、vi、アカウント管理、cron、ログ、ネットワークの設定
  • 進め方は、診断 → 学ぶ → 解く → 模試の輪。苦手の主題に戻って回す
