## この本について {#about}

この本は、**LinuC（リナック）レベル1** に合格するための学習書です。[図解 Linux](../../linux/site/index.html) を読み終えた人を前提にしています。

「読み終えた」といっても、全部を覚えている必要はありません。図解 Linux で身に付けたのは、プロセス、ファイルディスクリプタ、inode、パーミッション、シェルの仕組みです。この本では、その知識を**試験の形で引き出せるように**します。足りないところは、ここで補います。

図解 Linux とこの本の違いは、目的です。

| | 図解 Linux | 図解 LinuC |
| --- | --- | --- |
| 目的 | 仕組みを分かる | 試験で正しく選べる |
| 範囲 | カーネルの中まで深く | 出題範囲を広く、漏れなく |
| 中心 | 図と、小さな Linux で動かすこと | 本番の形の練習問題と、苦手の復習 |
| 覚えること | 少なく。仕組みから導く | オプション、ファイルの場所、ポート番号も覚える |

試験には、どうしても覚えるしかないものがあります。`useradd` の `-m` の意味、`/etc/cron.allow` の役目、`22/SSH` と `123/NTP` などです。この本は、覚えることを表にまとめ、練習問題で何度も引き出すことで定着させます。

:::note 問題はこのサイトのオリジナルです
練習問題と模擬試験は、出題範囲をもとにこのサイトが作ったものです。本番の問題を写したものではありません。形（選択肢の数、「2 つ選択してください」、コマンドを入力する問題）は、本番に近づけてあります。
:::

## 試験の形 {#exam}

LinuC レベル1 に認定されるには、**101 試験と 102 試験の両方**に合格します。どちらから受けてもかまいません。

| 項目 | 内容 |
| --- | --- |
| 問題の数 | 1 回約 60 問 |
| 時間 | 90 分（そのうち約 5 分は、試験の後のアンケート） |
| 形 | コンピュータで受ける（CBT）。ほとんどはマウスで選ぶ問題で、キーボードで入力する問題が少しある |
| 受験料 | 1 回 16,500 円（税込） |
| 認定の条件 | 101 と 102 の両方に、5 年以内に合格する |
| 合格点 | 公表されていない |

60 問を約 85 分で解くので、1 問にかけられるのは 1 分 20 秒ほどです。迷った問題に印を付けて先へ進み、最後に戻る、という時間の使い方が大事です。

合格点は公表されていません。この本の模擬試験では、**80% 以上を 3 回続けて取ること**を目標にします。本番の問題は、模試より見慣れない聞き方をしてくるからです。

:::warn 申し込む前に、公式のページを確かめる
受験料、試験の形、出題範囲は変わることがあります。上の表は、この本を書いたときに [LinuC の公式サイト](https://linuc.org/linuc1/) で確かめたものです。申し込む前に、もう一度公式のページを見てください。
:::

## 図解 Linux で学んだこと、ここで学ぶこと {#map}

図解 Linux とこの本の範囲を比べると、3 つに分かれます。

- **図解 Linux でほぼ足りる**：復習と、試験の形の練習だけでよい
- **一部を学んだ**：仕組みは分かっているので、コマンドとオプションを足す
- **図解 Linux になかった**：この本で一から学ぶ

| 主題 | 図解 Linux | この本で足すこと |

## 合格メソッド：診断 → 学ぶ → 解く → 模試 {#method}

```fig graph 合格メソッドの 4 段階。模試で見つけた苦手の主題へ戻り、輪を回す

  nodes: [
    { id: 'diag', label: '1. 診断', sub: '模試を 1 回', x: 0, y: 0, kind: 'plain', mono: false },
    { id: 'learn', label: '2. 学ぶ', sub: '苦手の主題の章を読む', x: 1, y: 0, kind: 'stack', mono: false },
    { id: 'drill', label: '3. 解く', sub: '章末の問題と復習', x: 2, y: 0, kind: 'crate', mono: false },
    { id: 'mock', label: '4. 模試', sub: '80% を 3 回', x: 3, y: 0, kind: 'accent', mono: false },
  ],
  edges: [
    { from: 'diag', to: 'learn' }, { from: 'learn', to: 'drill' }, { from: 'drill', to: 'mock' },
    { from: 'mock', to: 'learn', label: '70% 未満の主題へ', curve: 1, style: 'muted' },
  ],

```

1. **診断**：最初に[模擬試験](mock.html)を 1 回受けます。点数は気にしません。採点の後に出る「主題ごとの正答率」を見て、低い主題を 2〜3 個選びます
2. **学ぶ**：選んだ主題の章を読みます。図解 Linux で学んだ所は、章の中のリンクから戻って復習します。コマンドは、ページの中の小さな Linux で実際に打ちます
3. **解く**：章の最後の練習問題を解きます。まちがえた問題は記録され、[苦手を解く](review.html)のページに集まります。正解するまで繰り返します
4. **模試**：もう一度模擬試験を受けます。70% に届かない主題が残っていたら、2 に戻ります。80% 以上を 3 回続けて取れたら、本番を予約します

:::tip 選択肢の「ほかが違う理由」まで言えるようにする
練習問題の解説には、正解の理由だけでなく、ほかの選択肢がなぜ違うかを書いてあります。本番は、同じことを違う聞き方で問います。「この選択肢のオプションは、本当は何をするか」まで言えるようになると、聞き方が変わっても解けます。
:::

## 6 週間の計画 {#plan}

1 日 1 時間ほどで、101 と 102 を続けて受ける計画の例です。

| 週 | やること | 目安 |
| --- | --- | --- |
| 1 週目 | 序章、101 の模試で診断。1.03（コマンド）と 1.02（ファイル）の章 | 図解 Linux の復習が中心 |
| 2 週目 | 1.04（パッケージ）と 1.05（ディスク）の章 | 新しく覚えることが多い |
| 3 週目 | 1.01（インストール・仮想化・起動・プロセス）の章、苦手の復習、101 の模試 | 80% を目指す。届いたら 101 を予約 |
| 4 週目 | 102 の模試で診断。1.06（シェル）と 1.07（ネットワーク）の章 | サブネットの計算は手で何度も |
| 5 週目 | 1.08（システム管理）、1.09（サービス）の章 | 設定ファイルの場所を表で覚える |
| 6 週目 | 1.10（セキュリティ）、1.11（オープンソース）の章、苦手の復習、102 の模試 | 80% を 3 回で 102 を予約 |

101 と 102 の間を空けるなら、101 に合格してから 102 の計画を始めてもかまいません。2 つの合格は、5 年以内であれば認定されます。

## 練習問題の使い方 {#how}

練習問題は 3 つの形です。

- **1 つ選ぶ**：ラジオボタン
- **複数選ぶ**：チェックボックス。本番と同じく「2 つ選択してください」のように、選ぶ数を問題文に書きます
- **入力する**：コマンドやファイルの名前をキーボードで入力します。本番と同じく、**綴りが完全に合っていないと不正解**です。オプションの付け方が違う別解を認める問題もあります

試しに解いてみてください。

:::q 1.03.1-91 single
シェルの組み込みコマンドで、現在のシェルの中でスクリプトを実行し、スクリプトの中で設定した変数をそのまま残すものはどれか。
- [ ] `exec`
- [ ] `bash`
- [x] `source`
- [ ] `eval`
:::why
`source ファイル`（`. ファイル` と同じ）は、ファイルの中身を**いまのシェル**で実行します。そのため、スクリプトの中で設定した変数や `cd` が、終わった後も残ります。

- `bash ファイル` は、子プロセスの新しいシェルで実行するので、変数は残りません（[図解 Linux 7.10](../../linux/site/ch07.html#subshell)）
- `exec` は、いまのシェルをそのプログラムに入れ替えます。終わるとシェルごと終わります
- `eval` は、引数を 1 つのコマンドとして組み立てて実行します。ファイルは読みません
:::
:::

:::q 1.07.1-91 multi
暗号化された通信に使われるポート番号を 2 つ選択してください。
- [x] 22
- [ ] 25
- [ ] 80
- [x] 443
- [ ] 123
:::why
22 は SSH、443 は HTTPS で、どちらも暗号化された通信です。25 は SMTP（メール配送）、80 は HTTP、123 は NTP（時刻）で、どれもそれだけでは暗号化されません。ポート番号は 1.07.1 で表にして覚えます。
:::
:::

:::q 1.02.1-91 fill
ファイル `report.txt` の持ち主だけが読み書きでき、ほかのだれも何もできないようにする。`chmod` に与える 8 進数の権限を、3 桁の数字で入力してください。
= 600
= 0600
:::why
読み（r）は 4、書き（w）は 2、実行（x）は 1 です。持ち主に読み書き（4 + 2 = 6）、グループとその他には何も与えない（0）ので `600` です（[図解 Linux 4.3](../../linux/site/ch04.html#chmod)）。先頭に 0 を付けた `0600` も同じ意味です。
:::
:::

答えると、正解と解説が出ます。解いた結果はこのブラウザに記録され、ページを開き直すと「前回：正解」「前回：不正解」の印が付きます。

:::key まとめ
- LinuC レベル1 は 101 と 102 の 2 つの試験。1 回約 60 問・90 分。合格点は公表されていないので、模試で 80% を目指す
- 重要度の合計は各試験 60。重要度はだいたい出る問題の数
- 図解 Linux で足りない大きな範囲は、パッケージ管理、パーティションと LVM、vi、アカウント管理、cron、ログ、ネットワークの設定
- 進め方は、診断 → 学ぶ → 解く → 模試の輪。苦手の主題に戻って回す
:::
