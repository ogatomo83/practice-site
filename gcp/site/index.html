入れ物と権限から、主要サービスまで

Google Cloud（GCP）は、サービスの数が 100 を超えます。この本は、どのサービスにも共通する「入れ物」と「人」——組織・フォルダ・プロジェクト、リージョン、請求先、アカウントの種類、IAM——を先に固めてから、Cloud Storage、Compute Engine、VPC、Cloud Run、Cloud Run functions、Pub/Sub、Firestore、Cloud SQL、BigQuery、Cloud Logging に絞って説明します。本文の gcloud と bq のコマンドは、すべてブラウザの中の小さな GCP でその場で実行でき、リソースの木と IAM の継承を「クラウドを見る」で確かめながら読めます。本物の Google Cloud にはつながらないので、料金はかかりません。
