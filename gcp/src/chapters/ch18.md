## この付録の使い方 {#about}

本文を読み終えた後に、手元に置いて引くための付録です。

- **早見表**：コマンドを、やりたいことから探せます。右の列は、詳しく説明した節です
- **よく出るエラー**：エラーの文の決まった言い回しから、原因と直し方を引けます
- **このサイトの GCP と本物の違い**：模型の都合で、本物と違うところの一覧です。本物で試すときに読んでください
- **用語集**：この本に出てきた言葉を、五十音順ではなく、話題ごとに並べました

コマンドは、どれもこのページの下の「実験場」でも試せます。ここに書いたコマンドを実行するブロックは、1 つだけ置いておきます。

```sh run title="コマンドの使い方を、その場で調べる"
gcloud projects create --help
```

`--help` は、どのコマンドにも付けられます。このサイトの gcloud の `--help` は短い説明だけです。本物では、マニュアルのページ（NAME、SYNOPSIS、DESCRIPTION、FLAGS、EXAMPLES）が開きます。

## gcloud の共通の書き方 {#gcloud-basics}

gcloud のコマンドは、`gcloud グループ [サブグループ] コマンド 位置引数 --フラグ` の形です（[1.5](ch01.html#grammar)）。

| フラグ | 意味 | 例 |
| --- | --- | --- |
| `--project=ID` | このコマンドだけ、別のプロジェクトで | `gcloud services list --project=tsubame-public` |
| `--account=EMAIL` | このコマンドだけ、別のアカウントで | `gcloud projects list --account=alice@tsubame.example` |
| `--configuration=名前` | このコマンドだけ、別の構成で | `gcloud config list --configuration=default` |
| `--impersonate-service-account=EMAIL` | サービスアカウントを借りて実行（[5.6](ch05.html#impersonation)） | |
| `--format=…` | 出力の形（下の表） | `--format="value(projectNumber)"` |
| `--filter=…` | 行を絞る（下の表） | `--filter="labels.env=prod"` |
| `--flatten=…` | 入れ子のリストを 1 行ずつに開く | `--flatten="bindings[].members"` |
| `--sort-by=キー` | 並べる。`~` を付けると逆順 | `--sort-by=~createTime` |
| `--limit=N` | 先頭の N 行だけ | `--limit=3` |
| `--quiet`（`-q`） | 確認を出さずに、既定の答えで進む | `gcloud projects delete X --quiet` |
| `--log-http` | API に送る要求を表示する（[1.8](ch01.html#api)） | |

### --format の書き方 {#format}

| 書き方 | 出るもの |
| --- | --- |
| `--format=json` / `yaml` | 全部の項目を JSON / YAML で |
| `--format="value(name, status)"` | 値だけをタブ区切りで。シェルの変数に入れるときに使う |
| `--format="table(name, zone.basename(), status)"` | 見出しつきの表 |
| `--format="table(name:label=名前)"` | 見出しの名前を変える |
| `--format="csv(name, status)"` | CSV |
| `--format="yaml(bindings)"` | 選んだ項目だけを YAML で |
| `--format=none` | 何も出さない（作るだけのとき） |
| `.basename()` | URL や名前の最後の部分だけ |
| `.date("%Y-%m-%d")` | 時刻を書式どおりに |
| `.len()` | リストの長さ |
| `.yesno("あり", "なし")` | 値があるかどうか |

### --filter の書き方 {#filter}

| 書き方 | 意味 |
| --- | --- |
| `key=値` | 等しい（大文字・小文字は区別しない） |
| `key!=値` | 等しくない |
| `key:値` | 含む（語の頭から一致。`*` が使える） |
| `key:*` | 値がある |
| `key~正規表現` | 正規表現に合う |
| `key>値` `key<値` `key>=値` | 大小 |
| `A AND B`、`A OR B`、`NOT A`、`-A` | 組み合わせ |
| `labels.env=prod` | 入れ子の項目は `.` でたどる |

`gcloud logging read` のクエリは、この書き方に `severity>=ERROR`（重さの比べ）、`logName:"…"`（含む）、`LOG_ID("…")` を足したものです（[16.4](ch16.html#query)）。

## よく出るエラーと直し方 {#errors}

エラーの文には、決まった言い回しがあります。言い回しから、原因の見当が付きます。

| エラーの文（の一部） | 原因 | 直し方 | 節 |
| --- | --- | --- | --- |
| `… API has not been used in project … before or it is disabled` | そのプロジェクトで API が無効 | `gcloud services enable …` | [3.6](ch03.html#services) |
| `Billing account for project '…' is not found` / `UREQ_PROJECT_BILLING_NOT_FOUND` | 請求先がない | `gcloud billing projects link` | [4.2](ch04.html#no-billing) |
| `Permission '…' denied on resource '…'` / `does not have … access` | IAM の権限がない | エラーの文の権限を含むロールを、そのリソースか上の階層で付ける | [6.8](ch06.html#denied) |
| `The required property [project] is not currently set` | 既定のプロジェクトがない | `gcloud config set project ID` か `--project` | [3.4](ch03.html#config) |
| `Underspecified resource [...]. Specify the [--zone] flag.` | ゾーンかリージョンを決めていない | `--zone` か `gcloud config set compute/zone` | [8.2](ch08.html#create) |
| `The project ID you specified is already in use` | プロジェクト ID は世界で 1 つ | 別の ID にする | [2.3](ch02.html#id-name-number) |
| `The requested bucket name is not available` | バケット名は世界で 1 つ | 別の名前にする | [7.2](ch07.html#bucket-names) |
| `One or more users named in the policy do not belong to a permitted customer` | 組織のポリシーで社外の人を禁止している | 社内のアカウントかグループにする | [6.7](ch06.html#org-policy) |
| `Failed to impersonate [...]` | 借用の許可（TokenCreator）がない | サービスアカウントに `roles/iam.serviceAccountTokenCreator` | [5.6](ch05.html#impersonation) |
| `Request had insufficient authentication scopes` / `Provided scope(s) are not authorized` | VM のアクセススコープが狭い | `--scopes=cloud-platform` で作り直すか変更 | [8.5](ch08.html#scopes) |
| `Your client does not have permission to get URL` （403） | Cloud Run を呼ぶ権限がない・トークンがない | ID トークンを付けるか、`roles/run.invoker` | [10.3](ch10.html#auth) |
| `failed to start and listen on the port defined provided by the PORT=8080` | コンテナが PORT で待っていない | アプリを `process.env.PORT` で待たせるか `--port` | [10.6](ch10.html#port) |
| `The query requires an index` | Firestore の複合インデックスがない | `gcloud firestore indexes composite create` | [13.5](ch13.html#index) |
| `Invalid table name: \`…\` [Try using standard SQL …]` | bq がレガシー SQL で読んだ | `--use_legacy_sql=false` | [15.2](ch15.html#query) |
| `Unrecognized name: …` | BigQuery の SQL で、列名の書き間違い | 列名を直す（`bq show --schema`） | [15.2](ch15.html#query) |
| `Connection timed out`（curl、ssh、psql） | ファイアウォールや承認済みネットワークで止まっている | 許可のルールを足す | [9.4](ch09.html#implicit-deny) |

## このサイトの GCP と本物の違い {#diff}

### 全体

- **本物の Google Cloud にはつながりません。** 料金も、請求も、メールも発生しません。コンソール（Web の管理画面）もありません
- **時計は仮想です。** 2026 年 11 月 16 日の午前 9 時（UTC）から始まり、コマンドを打つと少しずつ、VM の作成やデプロイでは本物と同じくらい進みます。`sleep` は待たずに、時計だけを進めます
- **ID は乱数ではありません。** プロジェクト番号、メッセージ ID、IP アドレスなどは、名前と操作の順番から決まります。同じ操作をすれば、何度でも同じ値になります
- **出力の形は、本物の gcloud・bq に合わせてありますが、本物で照合できていないものがあります。** 公式ドキュメントの例に合わせたものは、細かい項目や空白が本物と違うことがあります。とくに、`describe` の YAML の項目の数、`--help` の中身、エラーの文の後ろの詳しい情報（`Help Token` など）は、本物より少なめです
- `gcloud` のコマンドは、この本で使うものだけです。本物にある数百のグループの多くは、ありません

### 入れ物と人

- 組織は 1 つ（`tsubame.example`）だけで、人は 5 人、グループは 2 つです。Google Workspace や Cloud Identity の管理画面はありません。`gcloud identity groups` の作成とメンバーの追加だけができます
- `gcloud auth login` はブラウザを開かず、引数のアカウントにすぐ切り替えます。パスワードも 2 段階認証もありません
- IAM のロールと権限は、この本で使うものだけです。基本ロール（Owner、Editor、Viewer）の権限は、本物の数千の権限の一覧ではなく、権限の名前の決まり（`.get`、`.list` など）から決めています。`gcloud iam roles describe roles/viewer` の権限の一覧は、このサイトが知っている権限の中から集めたものです
- 拒否ポリシー（deny policy）と、Policy Troubleshooter はありません
- 組織のポリシーは、`iam.allowedPolicyMemberDomains`、`iam.disableServiceAccountKeyCreation`、`storage.publicAccessPrevention`、`gcp.resourceLocations`、`compute.vmExternalIpAccess`、`storage.uniformBucketLevelAccess`、`iam.automaticIamGrantsForDefaultServiceAccounts` だけです
- 予算はアラートを送りません（メールがないため）。料金の集計もありません

### サービス

- **Cloud Storage**：`gcloud storage ls -r` に、本物の「接頭辞:」の見出しと空行がありません。`ls -L`（詳しいメタデータ）はありません。ACL（細かいアクセス制御）、署名付き URL、ソフト削除からの復元（`restore`）はありません
- **Compute Engine**：VM の中のシェルは小さく、`apt-get` で入るのは nginx、apache2 など少しだけです。`gcloud compute ssh` は `--command` で 1 回実行するだけで、対話の端末にはなりません。スナップショットからディスクを作ることはできません。イメージは代表的なものだけです
- **VPC**：下り（EGRESS）のファイアウォールのルールは、判定に使いません。VPC ピアリング、共有 VPC、ロードバランサはありません
- **Cloud Run と関数**：動かせるのは Node.js のコードだけです（express、Functions Framework、`@google-cloud/firestore` `pubsub` `bigquery`、`pg` の模型）。Dockerfile は `FROM node:…` か、サンプルのイメージ（`us-docker.pkg.dev/cloudrun/container/hello`、`gcr.io/google-samples/hello-app`、`nginx`）だけを組み立てます。`npm install` はせず、使えるモジュールは上のものだけです。インスタンスはいつも 1 つで、同時に来た要求を並べて処理することはありません。Cloud Run jobs はありません
- **Pub/Sub**：`seek`（確認済みのメッセージを取り戻す）とスナップショット、スキーマ、順序指定の保証はありません
- **Firestore**：データの読み書きは Node の SDK だけです。セキュリティルール、リアルタイムの変更通知（`onSnapshot`）、エクスポートはありません
- **Cloud SQL**：中身は PGlite（本物の PostgreSQL 18）ですが、作れるのは PostgreSQL のインスタンスだけです。`gcloud sql connect` は、承認済みネットワークに IP を一時的に足す動きをしません（足さなくてもつながります）。Cloud SQL Auth Proxy（`cloud-sql-proxy`）のコマンドはありません。psql の中の `CREATE DATABASE` で作ったデータベースは、`gcloud sql databases list` に出ません。高可用性（HA）とリードレプリカはありません
- **BigQuery**：SQL は DuckDB に書き換えて実行します。よく使う関数（COUNTIF、SAFE_DIVIDE、FORMAT_DATE、DATE_TRUNC、DATE_DIFF、DATE_ADD、UNNEST、QUALIFY、STRUCT …）は使えますが、すべてではありません。エラーの文は、本物の言い回しに寄せて書き直したものです。処理したバイト数は、参照した列と、パーティションの列への日付の比較から計算します。ビューを `SELECT *` で読んだときなど、本物より多めに見積もることがあります。スロット、予約（エディション）、BI Engine、ML はありません
- **Cloud Logging と Monitoring**：シンクが BigQuery に作るテーブルは、列を平らにした簡単な形です（本物は入れ子の列）。システムイベントの監査ログと、データアクセスの監査ログの設定（`auditConfigs`）はありません。アラートポリシーの評価とインシデント、通知は画面に出ません。稼働時間チェックは作れますが、実際には確かめに行きません

### シェル

- Cloud Shell のシェルは小さな模型です。変数、引用符、`$( )`、パイプ、`&&` `||` `;`、ヒアドキュメント、`for`、`if`、`[ ]`、リダイレクトが使えます。関数、配列、`while`、`case`、バックグラウンド（`&`）はありません
- 使えるコマンドは、`gcloud`、`bq`、`curl`、`node`、`psql`、`echo`、`cat`、`ls`、`mkdir`、`cd`、`rm`、`grep`、`head`、`tail`、`wc`、`sort`、`uniq`、`cut`、`tr`、`seq`、`base64`、`date`、`sleep` などです。`sed`、`awk`、`jq`、`docker`、`kubectl`、`terraform` はありません
- 作ったファイルは、ページを開き直すと消えます
